# PRISMA ABYSS モンスター再配置・再調整 v3 適用手順

## 適用方法

1. プロジェクトをバックアップしてください。
2. このZIPのルート階層をプロジェクトのルートへ上書きしてください。
3. `assets/monsters` は追加マージではなく、既存フォルダを削除してから本ZIPの同名フォルダへ置き換えてください。
4. Service Workerのキャッシュ名は更新済みです。ブラウザで旧キャッシュが残る場合は再読み込みしてください。

## 重要事項

今回の新旧モンスターIDは同じ6桁数値帯を再利用しています。そのため、画像を単純に追加上書きすると、旧画像が別モンスターの新IDとして残る可能性があります。`assets/monsters` のフォルダ単位置換が必須です。

セーブデータは `monsterIdSchemaVersion: 3` を保存し、v2以前のデータだけを一度移行します。図鑑、討伐数、進行中の戦闘・クエスト等に含まれるモンスターIDも移行対象です。

- 通常・レア・ボス・試験官等を含む完成形モンスター画像271点
