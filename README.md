# PRISMA ABYSS 修正ファイル（2026-08-04）

## 適用方法

リポジトリ直下の同名ファイルをバックアップしてから、次の2ファイルを上書きしてください。

- `equip_acquisition_card.js`
- `news.js`

`tests/validate_fix.js` は確認用であり、ゲーム本体への配置は不要です。

## 修正内容

### 1. 戦闘報酬の+3装備取得カード

戦闘報酬では、次の順序になるよう変更しています。

1. 戦闘ログへ装備ドロップを表示
2. 戦闘画面を維持したまま取得カードを表示し、結果ログを停止
3. 画面タップでカードだけを閉じる
4. 閉じる操作由来の合成クリックを吸収した後、結果ログを再開

カード表示中は `Battle.resultInputLocked` と最前面のcapture入力ガードを併用します。閉じるタップは戦闘結果送り、戦闘終了、ログ送りへ伝播しません。

- 「保管」「売却」ボタンを削除
- 画面タップ、Enter、Space、Escapeで閉じる
- 追加オプション、追加特性、シナジー、基礎特性を装備名・基礎能力と同じ右側カラムへ配置
- 通常フィールド報酬の+3装備カードも同じタップ操作へ統一

### 2. イベント戦闘が終了しない不具合

戦闘会話終了後に `battle_event` フェーズへ残った場合、次を中央復旧処理で再確認します。

- 死亡状態の更新
- 勝敗判定
- 実行中ターンへの同期復帰
- ターン外なら既存の入力復旧処理へ接続

形態移行ジャーナルまたはフェーズ移行ランナーが動作中の場合は既存処理を優先し、復旧処理を割り込ませません。

### 3. 更新履歴

既存の `2026/08/04` のNEWSレコードへ今回の2項目を統合しています。

## 手動確認項目

- 戦闘で+3装備を1個取得し、ドロップログ直後にカードが表示される
- カード表示中に連打しても、ログ送りや戦闘終了が発生しない
- カードを閉じた後だけ次の報酬ログが流れる
- +3装備を複数取得した場合、各ドロップログの直後に1枚ずつ表示される
- 通常装備（+2以下）ではカードが表示されない
- 戦闘中会話で最後の敵を倒した場合、会話後に勝利結果へ進む
- 戦闘中会話後も敵が残る場合、残りのターンまたは入力画面へ復帰する
- 形態移行を伴う戦闘で既存の専用演出が継続する
