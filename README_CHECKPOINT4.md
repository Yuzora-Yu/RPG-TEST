# 深淵再編・統合チェックポイント4

作成日: 2026-07-29

このZIPはチェックポイント2・3を完全に包含する、単独適用可能な累積更新パッケージです。
**以前のチェックポイントを先に適用する必要はありません。チェックポイント4だけをゲーム本体へ上書きしてください。**

今回、チェックポイント2で不足していた「各新規ダンジョン約5体の完全新規モンスター」と「専用ボスの正本登録」を是正しました。
モンスター・スキル・アイテムを実行時に追加する処理は廃止し、それぞれ `monsters.js`、`skills.js`、`items.js` に正本として登録しています。

## 安全な適用方法

1. 現在のゲームフォルダとセーブデータを別名でバックアップしてください。
2. このZIPをゲーム本体とは別のフォルダへ展開してください。
3. 展開した親フォルダの**中身**を、ゲーム本体の同じ相対パスへコピーして上書きしてください。
4. `assets/monsters` はフォルダごと置換せず、同梱された新規画像73ファイルを追加してください。既存画像を削除する必要はありません。
5. 既存セーブを使う場合は、複製したテスト用セーブで先に確認してください。
6. Service Workerを使用している場合は、更新後に再読み込みしてください。キャッシュ名はチェックポイント4用に更新済みです。
7. チェックポイント3を適用済みの場合、旧IDの画像は参照されなくなります。容量整理が必要な場合のみ `DELETE_OBSOLETE_CHECKPOINT3_MONSTER_IMAGES.txt` を確認し、バックアップ後に手動削除してください。

自動適用スクリプトは、誤ったゲームフォルダへの上書きを避けるため同梱していません。

## 画像差し替え方法

通常敵は原則として、モンスターIDと同じ画像IDを使用します。

例:

```text
モンスターID 856
assets/monsters/monster_000856.png
```

後日新しい画像を用意した際は、同じファイル名で画像だけ差し替えてください。`monsters.js` や描画処理の変更は不要です。

例外は次のとおりです。

- ヴェグナシス5対象: `assets/monsters/monster_302080.png` を共有
- アゼルガラグ第一形態: `assets/monsters/monster_302100.png`
- アゼルガラグ第二形態: `assets/monsters/monster_302101.png`

全画像の流用元は `docs/ABYSS_MONSTER_IMAGE_COPY_MAP_20260729.csv` に記録しています。

画像フォルダ内の `assets/monsters/今後画像変更予定のモンスターID一覧.md` に、画像差し替え対象となる全77モンスターID・73画像ファイル・現在の流用元を一覧化しています。

## ヴェグナシスとアゼルガラグ

- ヴェグナシスは `302080`～`302084` の5体を同時戦闘へ配置
- 各対象は個別のHP、能力値、属性、スキル、根性Lv、撃破順番号を持つ
- 描画時は5体の個別画像を隠し、共通画像を1体だけ表示
- 1対象撃破ごとに残存対象の最大HP・MP・能力を強化し、HP・MPを全回復
- 撃破ごとの戦闘内会話中はオートを停止し、終了後に復元
- ヴェグナシス勝利後はアゼルガラグ第一形態へ連続移行
- 第一形態HP0時は通常勝利を挟まず第二形態へ移行
- 第二形態移行時に味方を全回復し、光の神の加護を付与
- オクタプリズマで指定3スキルを封印し、深淵王の全能力を低下

詳細は `docs/ABYSS_BOSS_PLACEMENT_20260729.md` を参照してください。

## ドロップ設定について

通常敵は既存通常モンスターと同じ仕組みを使用します。
`monsters.js` の各モンスターに固定 `dropSeed` を持たせ、既存正本 `monster-drop-policy.js` が通常・レアのアイテムIDと確率を決定します。新規敵だけ別のドロップ処理を追加していません。

解決後の具体的なアイテム名と確率は `docs/ABYSS_MONSTER_ROSTER_20260729.csv` に出力済みです。
固定ボスはイベント報酬との重複を避けつつ、通常報酬を持つボスについて `monsters.js` に明示しています。
