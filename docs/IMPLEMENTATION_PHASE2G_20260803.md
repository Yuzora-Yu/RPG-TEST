# IMPLEMENTATION Phase2G 2026-08-03

## 実装範囲

Phase2Gの鍛冶、装備Rank表示、戦闘結果スキップに加え、作業中に報告されたセーブ互換・固定ボス描画・回復の泉の不具合をまとめて修正した。

属性大精霊イベントとオクタプリズムのアゼルガラグ戦ギミックは、新規シナリオを伴うため企画書まで作成し、ランタイム実装は承認待ちとした。

## 1. 素材鍛造 +3

### 正式マスター

新規 `blacksmith_master.js` を追加した。

- 5部位: 武器、盾、頭、体、足
- 8Rank帯: G/F/E/D/C/B/A/S
- 合計40レコード
- 既存素材マスター8カテゴリ×8グレード（ID2000〜2063）を正式参照
- +1→+2、+2→+3で必要数を個別定義
- ステータス倍率は既存の+値基準（+1=1.1、+2=1.3、+3=1.5）を正本化
- 強化後の倍率対象能力は、現在値への比率掛けではなく正式装備マスターの基礎値から再計算し、段階強化時の端数累積を防止
- 装備価値は正式Rankと到達+値の既存式から再計算

### UI

鍛冶屋に既存の合成・精錬・能力強化とは別の「素材鍛造」を追加した。

- +1/+2だけを対象表示
- 強化前後の名称、Rank、基礎能力を表示
- 必要素材の名称、所持数、必要数を表示
- 確認後に確定
- UID、オプション、特性、ロック、装備者を維持
- 素材鍛造回数を `blacksmithMaterialUpgradeCount` として累計統計へ正式登録

### 保存原子性

`App.runAtomicSaveMutation()` を追加した。

- 処理前にセーブデータ全体のスナップショットを取得
- 装備・素材・GEM・鍛冶経験値を同一処理で変更
- `App.save()` 失敗または例外時に、同じ `App.data` 参照へ全状態を復元
- 保存失敗時に装備だけ変化、素材だけ消失、通貨だけ消費する状態を防止

同じ危険があった既存の以下も共通方式へ移行した。

- +3装備合成
- オプション精錬
- オプション能力強化

## 2. 神鉄の鍛冶台

item ID `599998` を正式アイテムマスターへ追加した。

- 名称: 神鉄の鍛冶台
- 種別: 鍛冶道具
- 消耗品
- ショップ・通常ドロップ対象外

### 変換ルール

- 所持装備と仲間の装備中装備から任意に選択
- お気に入り/ロックは対象条件にしない
- 同じ部位、同じ `baseName`（武器種・防具種）を維持
- 現在Rank+10を目標に、最も近い上位の正式装備マスターを選択
- UID、+値、ランダムオプション、特性、ロック、装備状態を維持
- 変換先マスター由来の基礎能力、候補オプション、固有スキルへ更新

対象外:

- 対応する正式マスターを特定できない装備
- `specialEquip` / `noRandom` の特殊・レプリカ装備
- 真・装備
- 同系統に上位装備がない最高段階装備

変換前後の名称、Rank、基礎能力を表示して最終確認する。アイテム消費と装備変換は原子的保存で一度だけ確定する。

## 4. レベルアップログのスキップ

戦闘結果画面の左上に専用ボタンを追加した。

スキップ対象:

- レベルアップSE待ち
- 能力上昇ログ
- `▼`入力待ち
- 複数レベル間の待機
- 成長特性ログ待機

対象外:

- ドロップ
- 仲間加入/LB
- スキル進化の選択
- 特殊ボス勝利確定
- ボス勝利後イベント
- 通常戦闘中
- 戦闘外

既存の `Battle.resultSkipRequested` を利用しつつ、`resultLevelSkipActive` でレベルアップ区間だけに有効範囲を限定した。通常の結果画面タップは従来通りログ送り/終了だけを行い、後続結果を一括スキップしない。

## 5. ギルガメッシュ仲間能力

ギルガメッシュID902000の正式ルールへ以下を追加した。

- 比較対象: ゼノン charId 402
- 下限倍率: 110%

新規加入時と既存セーブ移行時の両方で、同レベルのゼノンを基準にHP、MP、攻撃、防御、速さ、魔力、魔防の全7能力を比較し、ギルガメッシュが110%以上になるよう下限補正する。

- 同レベルの保存済みゼノンがいれば、その実値と内部投影値の高い方を採用
- 保存済みゼノンがいなければ、現行成長式の平均値でLv1〜100を投影
- `ALL_SPECIAL`成長型も再適用
- 満タンだったHP/MPは補正後も満タン維持
- 非満タン時は元の残量比率を維持

## 6. セーブ互換修正

短期補正を `data.system.oneTimeMigrations` の明示IDへ整理した。

### 討伐数

302101が1以上、302100/302000/302001が0の場合、各討伐数を最低1へ補正する。旧V1完了フラグが誤って立っていたセーブも、新しいV2 IDで再試行する。

### 転生成長

転生済み通常仲間の旧成長量を、新しい「1回+10%、最大+50%」の累積成長重みへ一度だけ再構築する。

旧レベルアップ乱数・過去の成長特性・育成アイテム履歴が完全保存されていないため、完全な履歴再演ではなく集計値の安全な縮尺再構築である。今後の育成アイテムは `permanentStatBonuses` へ記録し、再構築対象から除外できるようにした。

### ルーナ/ゼノン残留ボス

対応クエスト完了済みセーブだけを対象に、旧戦後ボス描画コンテキストを初回のみ削除する。

- `pendingPostBattleBossVisual`
- `lastFixedBossEvent`
- `activeFixedBossContext`
- 非アクティブ戦闘に残った固定ボス情報

ゼノン勝利イベントには `postBattleBossSprite:false` を正式設定し、今後の残留も防止した。

短期補正と長期スキーマ移行の分類は `docs/COMPATIBILITY_MIGRATION_LEDGER_20260803.md` に整理した。
