# 道具メニュー タブUI改修履歴

更新日: 2026-07-27

## 対象

道具メニューのカテゴリタブのみを改修した。戦歴メニューなど、ほかのタブUIには変更を加えていない。

## 修正内容

- `item-tabs` が共通の `[id$="-tabs"]` 装飾へ巻き込まれ、外周が丸いパネルになる問題を解消。
- 道具メニュー専用の `item-tab-bar` / `item-tab-btn` を追加し、共通タブCSSへの依存を切り離した。
- 選択中のタブを黄色の塗りつぶしで明示。
- 非選択タブは暗色で統一し、各タブ間だけに細い区切り線を表示。
- 外周の角丸・囲みブロックを撤去し、横一列のフラットなナビゲーションへ変更。
- 4カテゴリを常に均等幅で表示。
- 各タブの高さを44px以上にし、スマートフォンでのタップ性を改善。
- タブを切り替えた際、アイテム一覧のスクロール位置を先頭へ戻すよう変更。
- `role="tablist"`、`role="tab"`、`aria-selected` を設定。
- キーボードの左右キー、Home、Endでもタブ移動できるようにした。
- Service Workerのキャッシュ名を `prisma-abyss-v3.153-item-tabs-ui` へ更新。

## 変更ファイル

- `index.html`
- `menus_items.js`
- `modern-polish.css`
- `sw.js`

## 動作確認について

依頼済みの方針に従い、ゲーム起動およびプロジェクト付属の検証ツールは実行していない。
