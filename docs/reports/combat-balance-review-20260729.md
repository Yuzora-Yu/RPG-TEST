# 戦闘バランス一次監査・初回調整記録

作成日: 2026-07-29

## 結論

監査結果を受け、装備基礎値、Rank26～85通常敵、固定ダメージ契約の初回調整を正本へ反映した。経験値とボス能力は変更していない。次段階では「想定レベル・装備Rank・限界突破・人数」を各地域に割り当て、その条件で与ダメージ、被ダメージ、撃破ターンを実測する。

優先順位は次のとおり。

1. 固定ダメージスキルの `rate: 0` と実行式の不一致は是正済み。
2. Rank26～85通常敵の攻撃・魔力・防御・魔防は初回調整済み。
3. 装備Rank上昇時の基礎値成長曲線は正本更新済み。
4. ボスは想定パーティーに対する撃破ターンと行動回数で調整する。
5. Lv49・Lv99の必要経験値スパイクは、明確な壁として現行仕様を維持する。

## 現行計算の性質

物理・魔法の1ヒット基礎値は概ね次式である。

`攻撃側能力 / 2 + スキルbase - 防御側能力 / 4`

その後にスキル `rate`、属性、最終ダメージ、最終軽減、乱数0.85～1.15などが乗る。したがって、同じ倍率の攻撃なら攻撃・魔力+20は基礎ダメージ約+10、防御・魔防+40は約-10に相当する。HPを増やさず攻防を調整したい今回の方針と相性がよい。

ただし、多段技では各ヒットに `base` が加わる。`count` が多い技へ大きなbaseを与えると、表示倍率以上に伸びるため、単純な `rate × count` 比較では足りない。

調整前の固定ダメージは `baseDmgCalc = base` の後も `rate` を乗算し、「メタル斬り」と「ロストプリズマ」がともに1ダメージになっていた。現在は攻撃側能力、相手の防御・魔防、スキル倍率、会心、隊列、種族特効、与ダメージ、属性耐性、乱数を参照しない専用分岐へ変更した。被ダメージ軽減、攻撃種別軽減、防御姿勢だけは適用する。実行検証ではメタル斬り2、ロストプリズマ999を確認済み。

実戦では装備、特性、ツリー、配分、限界突破がさらに加算・乗算される。特に限界突破は回数帯で基礎値換算率が10%から15%、20%へ変わるため、ボスをRankだけで合わせると誤差が大きい。地域ごとに想定ビルドを保存データとして用意する必要がある。

成長自体の振れ幅も大きい。通常の4～8%乱数に加えてひらめきとLv50/100の5～6倍成長があるため、同じキャラ・同じレベルでも素の能力差が生じる。ボス調整では平均値だけでなく下位25%系列も生存できるか確認する。

31～40は魔法型が集中しているためATK中央値が低いこと自体は役割差だが、DEFも16～23しかなく、物理攻撃で即座に崩れやすい。46～50はATKが41～45より下がり、56～60はDEFが51～55より下がる。個体差の範囲を超えてRank曲線に谷がある。

深淵追加帯のHP増加は比較的穏当だが、106～115で物理防御が下がる一方、魔力寄りになる。意図した敵役割なら問題ないが、地域全体の難度曲線としては「前Rankより柔らかい」と感じる可能性がある。

調整案:

- 各5体を「物理火力」「魔法火力」「物理壁」「魔法壁」「高速妨害/エリート」に分類する。
- HPは原則現状±10%内に置き、Rank帯ごとの基準攻撃値・基準防御値を先に作る。
- Rank26～40は物理型ATKと全体DEF/MDEF、Rank41～60は攻撃曲線の谷、Rank61～85は装備強化後の被ダメージを重点調整する。
- 初期案は、物理型ATKと魔法型MAGをRank26～50で約25～40%、Rank51～70で約15～25%、Rank71～85で約10～20%引き上げる。ただし、敵ごとのスキルbaseと行動回数を含めて個別決定する。
- 防御役以外のDEF/MDEFもRank26～60では底上げし、高Rank装備導入後も通常戦が一撃処理だけにならないようにする。
- 1戦の目標を通常2～4ターン、エリート4～6ターンとし、HPではなくDEF/MDEFで攻撃手段の選択を促す。
- 割合ダメージ、行動不能、全体技は能力値と別の脅威予算として数える。2回行動敵へ高確率妨害を重ねない。

初回実装では68体のHP・MP・EXP・ゴールド・生息地・行動・ドロップを維持し、ATK/MAG・DEF/MDEF・SPDだけを直接更新した。主火力平均は26～30で47→53、31～35で118→131、36～40で113→136、41～45で130→148、46～50で109→154、51～55で167→194、56～60で198→231、61～65で218→257、66～70で211→267、71～75で229→274、76～80で235→281、81～85で255→310。2回行動個体は上昇幅を抑えている。

## 経験値

SSRの必要経験値は、Lv49→50が240,000、Lv90→91が約195,000、Lv99→100が1,200,000。Lv49・Lv99は明確な育成の壁として意図された正常値であり、変更対象から外す。

通常敵EXPを調整する場合も、この壁を短縮する目的では行わない。壁以外のRank帯で戦闘回数が不自然に多い／少ない箇所だけを個別に扱う。

深淵新規ストーリーボス302000～302101と六属性精霊502001～502006はEXP 0である。イベント報酬へ完全移管する意図がなければ、攻略の節目として不自然なので要決定。

主人公6人の主能力はLv1からLv100まで概ね31～35倍になる。調整前のRank1から200の装備基礎値は剣15倍、斧13.5倍、杖12.25倍に留まっていた。現在は剣32倍、斧31.5倍、杖30.5倍へ改訂し、短剣・槍・弓もbaseName固有の配分を保った曲線にしている。

改訂案は、baseNameごとのRank1の特徴を始点として、Rank200で概ね28～32倍へ到達させる。

|---|---:|---|
| 剣 | ATK 90～100 | 命中を維持する安定型 |
| 斧 | ATK 120～130 | 最大火力、SPD・命中低下 |
| 槍 | ATK 100～110 | 剣より火力寄り、属性・会心 |

成長曲線の目安はRank1を1倍として、Rank50で約5～6倍、Rank100で約11～14倍、Rank150で約19～23倍、Rank200で約28～32倍とする。現在のRank50装備はこの曲線に比較的近く、主にRank70以降の伸びを強める形になる。

防具は同倍率で増やすと過剰防御になりやすいため、武器より緩いRank200で20～25倍を目安とする。`finDmg`、`finRed`、属性耐性、状態耐性は基礎値とは別予算で維持し、+1/+2/+3の1.1/1.3/1.5倍を適用した状態でも、一つ上の主要Rank帯の無印が選択肢に残る交差点を作る。

## スキル火力

ATK/MAG 400、対象DEF/MDEF 300、属性・特性・会心なしの概算では、上位技の差が大きい。

- クライムハザード: 全体約2,813
- ショック: 単体約2,100
- ストックブレイク: 全体約1,275
- フェニックスフレア: 単体約1,138
- アビスウォール: 全体約770
- メラガイアー: 単体約448

習得時期や敵専用技を無視した単純比較なので、数値を直ちに揃えるべきではない。ただし全体技が同MP帯の単体技を大幅に超える箇所、MP0の高倍率技、各ヒットへbaseが入る多段技は個別監査が必要。

スキルは「単体/全体/ランダム」「1行動の期待対象数」「MP」「追加効果」「命中」「防御無視」を含む総予算で比較する。火力だけを横並びにすると、妨害や属性弱点の価値を消してしまう。

## ボス

深淵ストーリーボスは、Rank85の将軍2体がHP10,500/11,500・2回行動、Rank120イルミナシアがHP29,000・3回行動、アゼルガラグがHP38,000から第二形態48,000へ連戦する。ヴェグナシスは5対象合計78,000HPに加え、撃破ごとの残存強化と全回復があるため、表示HP以上の耐久となる。

ボス調整は次の指標で行う。

- 通常ボス: 8～12ターン
- 節目ボス: 12～18ターン
- 最終連戦: 各ギミックを一度以上見せつつ、回復資源が尽きる前に終わる長さ
- 単体最大打撃: 標準前衛HPの35～50%以内
- 全体最大打撃: 標準後衛HPの20～35%以内
- 3回行動: 同一ターンに最大技が重複しない行動表を含めて評価

ヴェグナシスはHPを増やさず、柱を倒す順番で被ダメージと攻略法が変わるようATK/MAG/SPDを調整するのが適切。アゼルガラグは第一・第二形態を別々に強くするより、連戦全体の回復イベントとオクタプリズマ有無で目標ターンを分ける。

## 次の実測手順

1. Rank帯ごとに標準セーブを3種作る: 無作為装備、適正装備、厳選装備。
2. 各セーブで通常敵5種を各20戦し、勝利ターン、被ダメージ、MP消費、戦闘不能率を記録する。
3. ボスは下位25%成長・平均成長・上位25%成長で各10戦する。
4. 装備はRankごとの主能力寄与率と、低Rank+3対高Rank無印の勝率を比較する。
5. この実測後に、通常敵、装備、ボスの順で別々の差分として調整する。

本資料に記載した装備基礎値、Rank26～85通常敵、固定ダメージ分岐は実装済み。EXPとボス能力は未変更であり、ボスは標準セーブによる実測後に判断する。
