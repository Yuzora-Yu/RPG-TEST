# PRISMA ABYSS BGM・SE制作／実装指示書

作成日: 2026-07-25  
対象実装: `audio_manifest.js` / `audio.js`

## 1. 今回追加した枠

差し替え用の無音OGGを同梱し、以下を実装済みです。

- フィールド、町・拠点、各固定ダンジョン、施設、戦闘種別ごとのBGMスロット
- BGMのループ再生
- 戦闘・施設へ入る直前の再生位置保存
- フィールドへ戻った際の、同じ曲の保存位置からの再開
- BGM・SE音量（0～100）のセーブ、設定画面のスライダー
- 同一SEの過剰な連打を抑えるクールダウン
- SEの同時発音用簡易プール
- 全BGM・SEスロットに有効な無音OGGを配置し、同名ファイルの上書きだけで順次差し替え可能
- メニュー決定・メニューキャンセル／戻る操作の共通SEフック

音源の一覧とファイル名は `audio_manifest.js` を正本とします。

## 2. 音源差し替え手順

1. `docs/audio/AUDIO_PLACEHOLDER_FILE_LIST_20260725.md` から対象ファイル名を確認する。
2. 完成したOGGを、同じファイル名の無音OGGへ上書きする。
3. ブラウザを再読み込みし、設定画面で音量を確認する。
4. Service Worker利用環境では、更新後にオンライン状態で一度再生するか、キャッシュバージョンを更新する。
5. 全実音源をオフライン一括取得させる段階では、`assets.js` のウォームアップ対象へ追加する。音源容量が大きいため、App Shellへの全件直書きは避ける。

マニフェストは全スロット `enabled: true` です。通常の差し替えではJavaScriptの変更は不要です。

命名規則:

```text
BGM: assets/audio/bgm/bgm_<音源キー>.ogg
SE : assets/audio/se/se_<音源キー>.ogg
```

例:

```js
field_world: {
    src: 'assets/audio/bgm/bgm_field_world.ogg',
    title: '世界フィールド',
    group: 'field',
    loop: true,
    enabled: true
}
```

## 3. 推奨ファイル仕様

### BGM

- 形式: Ogg Vorbisで統一
- サンプルレート: 44.1 kHz または 48 kHz
- ビット深度: 制作時24 bit、ゲーム納品時は圧縮形式
- ラウドネス目安: -16～-14 LUFS Integrated
- True Peak: -1 dBTP以下
- ループ: クリックノイズのないシームレスループ
- 先頭無音: 原則50 ms未満
- 曲末: ループ点に余分な残響を残さない。残響を残す場合はループ先頭へ自然につながるよう焼き込む

### SE

- 形式: Ogg Vorbisで統一
- サンプルレート: 44.1 kHz または 48 kHz
- True Peak: -1 dBTP以下
- 先頭無音: 原則10 ms未満
- モノラル推奨: 壁衝突、会話、UI、足元系
- ステレオ可: 大型イベント、ワープ、戦闘開始、全体魔法

## 4. BGM制作指示

### 世界フィールド

- 長時間聴いて疲れにくい主旋律
- 冒険感は出すが、戦闘曲より音圧・情報量を抑える
- 2～4分程度の自然なループ

### 町・拠点

- 各地域の属性を音色で区別する
- 炎: 打楽器、低弦、鍛冶の金属感
- 風: 木管、軽い弦、空気感
- 水: ハープ、ベル、水面を思わせるアルペジオ
- 雷要塞: 規則的な低音、機構音を思わせるパルス
- 光宮殿: コーラス、鐘、透明な高域
- 魔王城: 低音合唱、重い和声。ただしクリア後拠点では威圧一辺倒にしない
- 深淵外縁: 不安定な持続音と観測拠点としての静けさ

### ダンジョン

- `audio_manifest.js` に固定ダンジョンごとの独立スロットを用意済み
- 町・拠点と同じマップキーでも、1階拠点用BGMと内部用BGMを分ける
- 短いループの反復感を避け、最低90秒以上を推奨
- 環境音を曲へ直接混ぜすぎず、将来の環境SEレイヤー追加余地を残す

### 施設

- 宿屋、商店、鍛冶屋、錬金所、カジノ、メダル交換所を独立
- 施設滞在が短いため、冒頭2～3秒で性格が伝わる構成
- フィールドへ戻ると、入店前BGMの途中位置から再開する

### 戦闘

- 通常戦闘: 素早い立ち上がり。雑魚戦が短くても成立する導入
- 中ボス: 通常戦闘より重いが、最終決戦の音色を使い切らない
- 大ボス: 地域章の決戦。強いフックと第二展開を持たせる
- ラスボス: 物語主題の回収を優先。専用イントロを許容
- 裏ボス: 規格外のテンポ、拍子、音色。ただし耳障りな高域を常用しない

戦闘データで明示的に指定する場合:

```js
App.data.battle.battleBgmType = 'mid';    // mid / big / final / secret
// または
App.data.battle.battleBgmKey = 'battle_bigboss';
```

指定がない場合は、`isBossBattle`、`isSpecialBoss`、`isEstark`、イベントID等から自動判定します。

## 5. SE制作指示

- `event_effect`: 汎用イベント演出。画面フラッシュや紋章出現に使える中立音
- `heal`: 通常回復。短く明瞭
- `heal_spring`: 回復の泉。通常回復より長く、清浄感を強める
- `chest_open`: 蓋の作動音＋短い獲得感。報酬レア度演出とは分離
- `encounter_start`: 画面が割れる瞬間に合う衝撃音。250～500 ms程度
- `menu_confirm`: メニュー決定。短く明瞭で、連続操作しても耳につかない
- `menu_cancel`: メニューキャンセル／戻る。決定音と音程または余韻を変えて区別する
- `dialogue`: 低音量の短い送り音。連続再生しても耳につかない
- `battle_attack`: 通常攻撃の基礎音
- `battle_skill`: スキル発動の汎用起動音。個別属性SE追加時の土台
- `battle_item`: 袋・瓶・使用決定を連想できる音
- `battle_damage`: 被弾の汎用音。多段攻撃向けに短くする
- `floor_move`: エリア接続やダンジョン侵入
- `stairs`: 上下階移動
- `warp`: 瞬間移動。定位が中央へ収束／拡散する設計が合う
- `damage_floor`: 毒沼・溶岩等。短く、連続歩行時にうるさくならない
- `switch`: 機構の起動。押下音と遠方作動音を一つにまとめすぎない
- `ice_slide`: 滑走開始を示す音。長いループ音ではなく短い開始音
- `wall_bump`: 軽い衝突音。長押し時はランタイム側で130 msの連打抑制

## 6. 再生位置復帰の仕様

- BGM切替前に現在の `currentTime` を曲キー別に保存する
- 戦闘または施設終了後、元の曲キーを再選択すると保存位置へシークする
- 曲長を取得できた場合、保存位置は曲長で剰余を取る
- セーブデータには曲の再生秒数を永続保存しない。ページ再読込後は曲頭から開始する
- 音源解禁前のブラウザでは、最初のタップ／キー入力後に再生を開始する

## 7. 実装者向け注意

- 新しいマップを追加したら `AREA_BGM` にマップキーを追加する
- 町とダンジョンが同じマップキーを共有する場合は `BASE_FLOOR_BGM` を利用する
- 新しいSEはマニフェスト登録後、処理側から `AudioManager.playSe('キー')` を呼ぶ
- 標準的なボタン操作は共通フックで `menu_confirm`／`menu_cancel` を自動判定する
- 個別指定は要素へ `data-audio-se="confirm"`、`data-audio-se="cancel"`、無音化は `data-audio-se="none"` を設定する
- 同じBGMを毎フレーム指定しても再生成されない。`playBgm` は同一キーを再利用する
- 音源ロード失敗時は警告のみで進行を止めない
- BGMとSEのマスター音量追加が必要になった場合、既存の2値を壊さず別設定として追加する

## 8. 受入確認項目

- BGM 0%で無音になり、SE音量は維持される
- SE 0%で無音になり、BGM音量は維持される
- フィールド曲の途中で戦闘し、勝利後にほぼ同じ位置から復帰する
- 施設出入りでも同様に復帰する
- 全BGMがループ端でクリックしない
- 壁へ長押ししても衝突音が過密にならない
- 多段攻撃でSEが破綻しない
- メニュー決定時に `se_menu_confirm.ogg` が鳴る
- 戻る・閉じる・キャンセル時に `se_menu_cancel.ogg` が鳴る
- 音源ファイルを一つ欠いてもゲームが停止しない
- モバイルSafari／Chromeで初回操作後に再生される

## 9. 同梱無音OGGについて

- BGM: 39ファイル、2.0秒、44.1 kHz、ステレオ、Ogg Vorbis
- SE: 19ファイル、0.15秒、44.1 kHz、モノラル、Ogg Vorbis
- 無音ファイルは実装確認と段階的な差し替えのための仮素材
- 実音源へ差し替える際は、ファイル名と配置場所を変更しない
- Gitや配布ZIPでは無音OGGも削除せず、未制作枠を明確に残す
