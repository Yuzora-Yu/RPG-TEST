# PRISMA ABYSS BGM・SE制作／実装指示書

作成日: 2026-07-25  
対象実装: `audio_manifest.js` / `audio.js`

## 1. 音量区分

設定画面では以下の5系統を独立調整します。

- フィールドBGM（戦闘以外）: 初期値30%
- 戦闘BGM: 初期値30%
- UI・メニューSE: 初期値5%
- 戦闘SE: 初期値5%
- フィールド・イベントSE: 初期値5%

旧セーブに従来の `bgmVolume` / `seVolume` だけがある場合、その値を対応する新カテゴリへ引き継ぎます。新カテゴリの保存値がある場合は上書きしません。

## 2. 音源枠と差し替え

- BGM: 42ファイル
- SE: 34ファイル
- すべて有効化済みの無音OGGを同梱
- 完成音源を同名ファイルで上書きするだけで反映
- 一覧・進捗管理表: `assets/audio/RPG_TEST_OGG音源管理表_20260725.xlsx`

BGMは `assets/audio/bgm/bgm_<キー>.ogg`、SEは `assets/audio/se/se_<用途>.ogg` の命名規則です。正確なファイル名は `audio_manifest.js` と一覧表を正本としてください。

## 3. 追加BGMの制作意図

### 船移動 `bgm_field_ship.ogg`

- 世界フィールド曲より水上移動の開放感を強める
- 長時間の探索でも疲れにくいテンポ
- 船から降りると通常フィールド曲の保存位置へ戻る

### 翼飛行 `bgm_field_wing.ogg`

- 高空・高速移動・視界の広がりを表現
- 船曲より軽く、上方向へ抜ける音色を推奨
- 飛行終了後は通常フィールド曲の保存位置へ戻る

### 全滅 `bgm_battle_wipeout.ogg`

- 全滅ログを読み返す時間を妨げない静かな敗北曲
- 自動遷移せず、タップ／Enterで終了するまでループ
- 長すぎるイントロや大音量の衝撃音は避ける

## 4. SEの制作意図

### UI・メニューSE

- `se_ui_item_heal.ogg`: 回復系道具
- `se_ui_item_move.ogg`: 移動系道具
- `se_ui_item_growth.ogg`: 育成系道具
- `se_ui_skill_heal_revive.ogg`: メニュー内の回復・蘇生スキル
- `se_ui_blacksmith_start.ogg`: 鍛冶開始。終了後に結果表示へ進むため、1～2秒程度を想定
- `se_ui_alchemy_start.ogg`: 錬金開始。終了後に結果表示へ進むため、1～2秒程度を想定
- `se_ui_shop_buy.ogg`: 購入成立
- `se_ui_shop_sell.ogg`: 売却成立

### 戦闘SE

- `se_battle_skill_magic.ogg`: 魔法スキル発動（旧汎用スキル枠を改称）
- `se_battle_skill_breath.ogg`: ブレススキル発動
- `se_battle_skill_physical.ogg`: 物理スキル発動
- `se_battle_skill_other.ogg`: 強化・弱体・特殊などその他スキル
- `se_battle_heal.ogg`: HP・MP回復、蘇生、吸収回復
- `se_battle_critical.ogg`: 会心・魔力暴走の成立
- `se_battle_victory.ogg`: 勝利ログの直後に再生し、終了後に報酬ログへ進む
- `se_battle_level_up.ogg`: レベルアップ通知後に再生し、終了後に成長詳細を表示

短い多段SEは連続発音を想定し、音尾を長くしすぎないでください。勝利・レベルアップ・鍛冶・錬金SEは処理進行が音源終了を待つため、不要な長尺や末尾無音を避けてください。

## 5. 推奨ファイル仕様

### BGM

- Ogg Vorbis、44.1kHzまたは48kHz
- -16～-14 LUFS Integrated目安、True Peak -1dBTP以下
- シームレスループ
- 先頭無音50ms未満

### SE

- Ogg Vorbis、44.1kHzまたは48kHz
- True Peak -1dBTP以下
- 先頭無音10ms未満
- UI・壁衝突・会話はモノラル推奨
- 勝利、レベルアップ、鍛冶、錬金は末尾無音を含めず、必要な余韻だけ残す

## 6. 再生・進行仕様

- BGM切替前に曲キーごとの再生位置を保存
- 戦闘・施設・船・翼の終了後、元のBGMへ保存位置から復帰
- 勝利: 勝利ログ → 勝利SE終了 → 報酬ログ
- レベルアップ: レベルアップログ → レベルアップSE終了 → 成長詳細表示 → タップ／Enter待ち
- 全滅: 全滅ログと全滅BGM → タップ／Enter待ち → 画面遷移
- 鍛冶・錬金: 開始SE終了 → 素材消費・抽選・結果表示
- 宝箱トラップ: 開封後に約650ms待機 → エンカウント演出

## 7. 受入確認

- 5つの音量スライダーが相互に干渉しない
- 船・翼・全滅BGMが正しい状態で選ばれる
- フィールド曲が戦闘・施設・移動専用曲の後に途中位置から戻る
- 全滅時に自動遷移しない
- レベルアップ詳細が入力待ちで停止する
- 鍛冶・錬金結果が開始SEより先に表示されない
- 勝利報酬ログが勝利SEより先に表示されない
- すべての無音OGGを実音源へ同名差し替えできる
