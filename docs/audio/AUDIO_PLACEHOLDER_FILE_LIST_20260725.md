## 差し替え時の注意

- Ogg Vorbis形式を使用する。
- ファイル名・拡張子・配置場所を変えない。
- BGMはシームレスループを前提に書き出す。
- SEは先頭の無音を極力短くする。
- 差し替え状況は `assets/audio/RPG_TEST_OGG音源管理表_20260725.xlsx` に記録する。
