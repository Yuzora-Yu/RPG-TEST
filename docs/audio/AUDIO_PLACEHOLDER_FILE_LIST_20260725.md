## 差し替え時の注意

- Ogg Vorbis形式を使用する。
- ファイル名・拡張子・配置場所を変えない。
- BGMはシームレスループを前提に書き出す。
- SEは先頭の無音を極力短くする。
- ブラウザキャッシュが残る場合はハード再読み込みする。
