# オクタプリズマ × アゼルガラグ戦ギミック仕様 2026-08-03

Status: **実装済み／初期バランス調整対象**

## 対象

item ID `701008` **オクタプリズマ**を所持した状態で開始する、次の本編ボス戦。

- 302100 深淵王アゼルガラグ（第一形態）
- 302101 深淵王アゼルガラグ・終極（第二形態）

ストーリーボス訓練所は対象外。アイテムは使用も消費もせず、戦闘開始時の所持状態を `battle.octaprismState` へ固定する。一度 `possessedAtBattleStart` を保存した後は、再読込・形態移行時に現在の所持数を再参照しない。

## 主人公の混沌属性耐性

主人公（character ID 301）の戦闘中混沌属性耐性を最低90%にする。

```text
戦闘中の混沌耐性 = max(通常計算後の値, 90)
```

- 90%以上なら変更しない。
- 装備、恒久能力、通常セーブ上の耐性は変更しない。
- 第一形態から第二形態へ移っても維持する。
- 戦闘再開時は戦闘用Playerへ再適用する。
- 仲間の戦闘不能・蘇生に伴う編成オーラ再計算で通常耐性へ戻った場合も、再計算直後に90%下限を復元する。

## 六精霊支援

各ターン開始時、行動順決定前に**50%**で発動する。発動時は火、水、風、雷、光、闇から一つを抽選する。直前に発動した精霊は次回候補から外し、同じ支援の連続を避ける。同じターン番号の実行経路へエラー復旧等で戻った場合は、最初に確定した発動・不発結果を再利用する。

演出で戦闘進行を止めない。効果ログを表示し、`PolishBattleFX.screenEffect()` により属性別の画面エフェクトを重ねる。

| 属性 | 実装効果 | 画面エフェクト |
|---|---|---|
| 火 | 敵全体へ最大HPの4%ダメージ。第一形態上限4000、第二形態上限6000 | fire |
| 水 | 味方全体の最大MP15%回復。戦闘不能者もMP回復可 | ice（水系表示） |
| 風 | 生存者全体の最大HP18%回復。蘇生なし | wind |
| 雷 | 敵全体へ最大HPの3%ダメージ。第一形態上限3200、第二形態上限4800。さらに守備力15%低下、そのターンのみ。闇の全能力低下とは別枠 | thunder |
| 光 | 味方全体の全属性耐性+50%、そのターンのみ | light |
| 闇 | 敵全体の攻・防・速・魔・魔防を10%低下、2ターン。重複時は弱い値へ戻さず残りターンを更新 | dark |

火・雷支援はHP1で止めず、とどめを刺せる。第一形態を倒した場合は通常の形態移行ジャーナルへ接続し、第二形態の戦闘チェーンを維持する。

## 戦闘状態

```js
battle.octaprismState = {
  version: 1,
  eligible,
  possessedAtBattleStart,
  active,
  heroChaosResistance: { characterId, before, after, applied },
  lastSpirit,
  turnSupport,
  supportHistory,
  activationLogged,
  legacyManualUseConverted
}
```

`battle.turnNumber` はターン開始時に加算する。支援結果は同ターンの戦闘状態へ保持し、通常のターン終了保存で敵・味方状態と同時に永続化する。ターン実行中にページを更新した場合は、従来の戦闘仕様どおり最後に保存済みの入力状態から再開する。同一ターン番号が保存済みの場合は `turnSupport` を再利用し、支援回復・攻撃・抽選を二重適用しない。

## アイテム仕様変更

`items.js` のitem ID701008は次の正式仕様へ変更した。

- 名称: `オクタプリズマ`のまま。
- `battleUsable: false`
- `fieldUsable: false`
- `consumable: false`
- 旧 `effectKind: octaprism` と `specialBattleItem: octaprism` を削除。
- 説明文を所持発動型へ更新。

旧UIや戦闘途中セーブから手動使用命令が残った場合、`ItemRuntime` は消費・敵弱体を行わず「所持効果である」旨だけをログへ返す。

## 旧戦闘途中セーブ

旧 `battle.abyssOctaprismUsed` が残る場合は `octaprismState.legacyManualUseConverted` として新状態へ取り込む。旧版で既に敵へ付いた永続弱体は途中戦闘の互換性のため維持するが、新規戦闘では旧手動弱体処理へ入らない。

この旧互換経路は、2026-08-15以降の互換整理時に削除候補として再監査する。

## 回帰観点

- 未所持、対象外ボス、訓練所では発動しない。
- 混沌耐性89→90、90→90、120→120。
- 発動率が50%。
- 同じ精霊が連続しない。
- ログだけで進行し、会話・入力待ちを作らない。
- 六属性の画面エフェクトを呼ぶ。
- 第一形態撃破時に第二形態へ正常移行する。
- 戦闘終了後に主人公の恒久耐性を変更しない。
- オクタプリズマを消費しない。
