# オクタプリズム × アゼルガラグ戦ギミック仕様案 2026-08-03

Status: **設計・バランス承認待ち（ランタイム未実装）**

## 目的

item ID `701008` を戦闘中に手動使用する方式を廃止し、所持してアゼルガラグ戦へ入るだけで発動する専用ギミックへ置き換える。

対象:

- 302100 深淵王アゼルガラグ（第一形態）
- 302101 深淵王アゼルガラグ・終極（第二形態）

## 基本原則

- アイテムは消費しない。
- 装備・恒久耐性・セーブ上の主人公能力を書き換えない。
- 戦闘開始時の所持判定結果を戦闘スナップショットへ保存し、再開時に再判定しない。
- 第一形態から第二形態へ移る際も同じ戦闘ギミック状態を引き継ぐ。
- カットインをスキップしても支援効果は消えない。
- 同一ターン・同一戦闘IDで二重発動しない。

## 1. 主人公の混沌属性耐性下限

### 仕様

オクタプリズム所持状態で対象戦闘を開始した場合、主人公の**戦闘中の混沌属性耐性を最低90%**にする。

```text
最終混沌耐性 = max(通常計算後の混沌耐性, 90)
```

- 通常計算で90%以上なら変化なし。
- 主人公のみ対象。
- 第一形態・第二形態の両方で有効。
- 戦闘終了時に自動で消える。
- 敵の耐性無視、個別技の防御貫通等がある場合は、その技仕様を別途適用する。

### 実装案

`App.calcStats()` の恒久値へ混ぜず、戦闘開始時Player生成後に `Battle.applyOctaprismHeroChaosFloor()` を一度適用する。元値と適用値を `battle.octaprismState.heroChaosResistance` へ保存する。

## 2. 毎ターンの六精霊支援

### 発動タイミング

- 各ターン開始時、通常の行動順決定前。
- 第一ターンから発動する。
- フェーズ移行直後に同じターン番号で再発動しない。
- 全滅確定後、勝利確定後、会話中は発動しない。

### 抽選

- 火、水、風、雷、光、闇の6種から1つ。
- 直前に発動した属性は次の抽選候補から外す。
- 戦闘スナップショットへ抽選履歴と現在ターンの確定属性を保存する。
- 再読込時は再抽選せず、確定済み支援を一度だけ適用する。

## 3. 支援効果の初期バランス案

| 属性 | カットイン役割 | 効果案 | 制約 |
|---|---|---|---|
| 光 | 守護 | 味方全体の火・水・風・雷・光・闇耐性+50%、そのターンのみ | 混沌耐性は別ギミックのため加算しない |
| 水 | 循環 | 味方全体の最大MPの15%回復 | 戦闘不能者もMPだけは回復可、最大値超過なし |
| 風 | 癒やし | 生存者全体の最大HPの18%回復 | 戦闘不能蘇生なし |
| 火 | 強襲 | 敵全体へ火属性の精霊攻撃 | ボス最大HP依存に上限を設け、戦闘を自動勝利化しない |
| 雷 | 破砕 | 敵全体へ雷属性の強攻撃＋そのターン防御低下 | 防御低下は既存デバフ耐性・下限ルールを守る |
| 闇 | 弱体 | 敵全体の攻・防・速・魔・魔防を10%低下、2ターン | 同効果は重複せず残りターン更新 |

### 攻撃支援の推奨式

火・雷はプレイヤー能力に依存させず、戦闘バランスを安定させる。

```text
基礎ダメージ = min(対象最大HPの4%, 固定上限)
```

- 第一形態と第二形態で固定上限を分ける。
- 防御、属性耐性、最終ダメージ軽減のどこまでを受けるかは既存精霊攻撃ルールに合わせる。
- 支援だけでとどめを刺せる仕様にするかは承認事項。推奨は「HP1で止めない」、総力戦の結果として撃破可能。

## 4. 演出

- 画面を長時間止めず、1〜1.5秒程度の短いカットインを基本とする。
- 左右から大精霊画像、中央に属性名と一言、直後に効果演出。
- リザルトのレベルアップスキップとは別機能。
- 戦闘設定の演出短縮、またはカットインタップで表示だけ短縮できる。
- 表示を飛ばしても効果適用とジャーナル記録は必ず行う。

## 5. セーブ・結果ジャーナル

推奨構造:

```js
battle.octaprismState = {
  version: 1,
  itemId: 701008,
  possessedAtBattleStart: true,
  targetBossIds: [302100, 302101],
  heroChaosResistance: { before, applied: 90 },
  lastSpirit: null,
  turnSupport: {
    turnNo,
    phaseBossId,
    element,
    state: 'prepared|applied|presented',
    effectSnapshot
  },
  supportHistory: []
}
```

適用順:

1. ターン支援を抽選し `prepared` 保存。
2. 効果を一度適用して `applied` 保存。
3. カットイン表示後 `presented` 保存。
4. 再読込時は状態に応じて未完了段階だけを続行。

## 6. 第一形態から第二形態への継承

現行の `phaseTransition.preserveOctaprism` と `abyssOctaprismUsed` は、手動使用型の敵デバフ継承を想定している。新仕様では以下へ置き換える。

- `phaseTransition.preserveOctaprismState: true`
- 主人公の混沌耐性下限状態を再適用。
- `lastSpirit` とターン支援履歴を維持。
- フェーズ移行時の全回復・バフイベントと精霊支援を別処理にし、同一効果として重複させない。

## 7. 旧手動使用処理の整理

承認後、以下を段階的に廃止する。

- item ID701008の `battleUsable: true`
- `effectKind: 'octaprism'`
- `specialBattleItem: 'octaprism'`
- 敵へオクタプリズム効果を付ける `Battle.applyOctaprismToEnemy()` 系処理
- `battle.abyssOctaprismUsed` の旧意味

旧戦闘途中セーブを再開できるよう、旧 `abyssOctaprismUsed` がある場合は新 `octaprismState` へ一度変換する互換処理を用意する。

1. 正式名称を「オクタプリズム」へ統一するか。
2. 光支援の+50%対象を通常六属性だけにするか、混沌も含めるか。推奨は通常六属性のみ。
3. 火・雷支援がボスへとどめを刺せる仕様でよいか。
4. 水支援を最大MP15%、風支援を最大HP18%として開始してよいか。
5. 闇デバフを10%・2ターン・非重複としてよいか。

## 回帰テスト計画

- アイテム未所持では一切発動しない。
- 対象外ボスでは発動しない。
- 主人公混沌耐性89→90、90→90、120→120。
- 第一形態から第二形態へ状態維持。
- 同じ精霊が連続しない。
- ターン開始中の保存/再読込で二重回復・二重攻撃しない。
- カットインスキップで効果が失われない。
- 戦闘結果ジャーナルとボス勝利イベントを壊さない。
