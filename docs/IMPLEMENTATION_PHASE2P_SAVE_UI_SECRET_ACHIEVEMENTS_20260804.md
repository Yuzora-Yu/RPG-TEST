## 1. セーブ画面

### 設定メニュー

削除対象をユーザー指示どおり限定した。

- 「セーブデータ管理」の説明ブロックを削除。
- 「セーブ」ボタン内の説明文を削除。
- 「ロード」ボタン内の説明文を削除。
- データ出力、データ読込、一括ダウンロードの説明文は維持。

### 確認画面の不具合

原因は、セーブスロット画面が `z-index:1000005`、従来の共通確認画面がそれより低い層に生成されていたことだった。スロット選択時に確認自体は生成されるが背後へ隠れ、「もどる」でスロット画面を閉じた後に初めて見えていた。

修正後は、確認・完了・エラー表示をセーブスロット画面自身の子レイヤーへ生成する。

- スロット選択直後に最前面で確認を表示。
- 背景タップは確認の「いいえ」扱い。
- 「もどる」はスロット画面を閉じるだけで、確認を新規発生させない。
- 保存完了・失敗メッセージも同じ最前面層で表示し、閉じるまで再描画しない。

### プレイ時間と現在エリア

- プレイ時間の正本・表示形式は既存Phase2Mの `hhhh:mm:ss` を維持。
- 表示幅を10文字へ限定し、ミリ秒等が入り込まない契約をCSSでも固定。
- 現在エリアを伸縮可能領域として明示し、プレイ時間より先に不要な省略が起きにくい配置へした。

## 2. 鍛冶レベル10実績

実績ID `503`「神工の槌音」の報酬を次へ差し替えた。

- 神鉄の鍛冶台 (`itemId:599998`) ×1

旧報酬のGEM・GOLDは新規受取時には付与しない。

### 旧セーブ救済

実績マスターへ `rewardVersion` を導入した。ID503はversion 2とする。

- 旧報酬を受取済みで、version情報を持たないセーブはversion 1受領済みとして移行。
- 実績の達成状態は維持。
- 現行version 2だけを一度受取可能にする。
- 新報酬受取後は `claimedRewardVersion:2` を保存し、再受取を防ぐ。
- 他の既存実績はversion 1受領済みとして扱い、意図しない再受取を発生させない。

報酬付与は `App.runAtomicSaveMutation()` が利用可能な環境では、アイテム付与・受取version更新・保存を一括確定する。保存失敗時は変更を取り消す。

## 3. secret実績

実績マスターで `secret:true` を指定可能にした。

未達成のsecret実績は次のすべてから除外する。

- 実績一覧
- カテゴリ候補
- 達成数・未達成数
- 達成率の分母
- 表示中件数

達成後は通常実績として表示され、報酬を受け取れる。

今回secret指定した既存実績:

- ID401 旅立ちの決意
- ID402 世界の真実
- ID2201 深淵王の終焉

内部では達成判定を継続するため、一覧に出ていない間も条件達成を失わない。
