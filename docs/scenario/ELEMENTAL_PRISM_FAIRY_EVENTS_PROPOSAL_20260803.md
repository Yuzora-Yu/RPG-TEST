## 実装済みイベントフロー

### 初回

1. 属性別の戦闘前会話を再生。
2. 「試練を受ける／今は退く」の選択肢を表示。
3. 受諾時だけ正式ボス戦へ移行。
4. 退いた場合は報酬・敗北履歴・試行回数を変更しない。

### 敗北後

- 敗北トランザクション内で `lostOnce` と敗北戦闘IDを保存する。
- 次回接触時は属性別の再挑戦台詞へ切り替える。
- 加護、結晶片、オクタプリズマは付与しない。

### 勝利後

- 勝利結果コミット時に、加護と属性結晶片を一度だけ確定する。
- 状態を `victory` として保存し、戦後イベントをキューへ積む。
- フィールド復帰後、属性別の承認会話を再生して `completed` へ進める。
- 会話中の再読込では報酬を再付与せず、イベントジャーナルから再開する。

### 六個目

1. 最後の大精霊の勝利後会話を完了。
2. 六つの加護が呼応する共通会話を再生。
3. 光の神が `オクタプリズマ` を一度だけ授与。
4. `abyssOctaprismGrantPending` を解除し、授与イベント完了を保存。

オクタプリズマは戦闘ドロップへ直接入れず、光の神の授与イベントで確定する。これにより六個目の勝利結果と授与会話の途中保存を独立して復元できる。

## 保存スキーマ

```js
progress.abyssSpiritTrialEvents[element] = {
  state: 'untouched|challenged|lost|victory|completed',
  attempts,
  lostOnce,
  lastAttemptAt,
  lastLossAt,
  lastLossBattleId,
  lastVictoryAt,
  victoryBattleId,
  completedAt
}
```

関連正本:

- 加護: `progress.abyssSpiritBlessings[element]`
- 六属性完了: `progress.flags.abyssAllSpiritTrialsCleared`
- 授与待ち: `progress.flags.abyssOctaprismGrantPending`
- 授与演出済み: `progress.flags.abyssOctaprismGrantEventSeen`
- 戦闘結果: `battle.resultJournal.elementalSpiritTrialOutcome`

## 旧セーブ互換

`App.ensureAbyssSpiritTrialEvents()` が次を行う。

- 加護取得済み属性は、再戦を要求せずイベント完了へ移行。
- ただし今回の勝利後会話待ちを示す `victory` は維持。
- 六加護取得済み・オクタプリズマ未所持なら、共通授与イベントを一度予約。
- 既にオクタプリズマ所持済みなら、重複付与せず授与済みとして整合。
- 授与演出済みフラグだけが残りアイテム本体を欠く場合は、授与イベントを再度予約して欠損を救済。

## 仮会話の方向性

- 火: 守るために燃える意志。
- 水: 揺らぎの中でも自分と仲間を失わないこと。
- 風: 誰かを置き去りにせず前へ進むこと。
- 雷: 速さを独走ではなく決断と連携へ使うこと。
- 光: 影を切り捨てない正しさ。
- 闇: 弱さや恐れを否定せず、支配もされないこと。
- 光の神: 六属性を集めた事実より、異なる力と共に歩いた選択を認める。
