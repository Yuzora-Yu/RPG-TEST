# 六属性プリズム・大精霊試練イベント企画 2026-08-03

Status: **企画・承認待ち（ランタイム未実装）**

## 目的

現在は各地のプリズムを調べると即座に大精霊戦が始まり、勝利結果画面だけで加護と報酬が付与される。これを、プレイヤーが六属性の大精霊に試され、認められ、最後に六つの力が一つへ結ばれるイベントとして見せる。

既存の元素順、加護の効果、ボスID、報酬IDは維持する。新規台詞・イベントデータは本書の承認後に実装する。

## 提案するイベント状態

属性ごとに、加護取得フラグとは別に演出状態を持つ。

```text
untouched   未接触
challenged  戦闘開始済み
lost        一度以上敗北
victory     勝利結果は確定済み、勝利後会話待ち
completed   加護授与会話まで完了
```

推奨保存先:

```js
progress.abyssSpiritTrialEvents[element] = {
  state,
  attempts,
  lostOnce,
  victoryBattleId,
  completedAt
}
```

加護とアイテム付与は戦闘結果ジャーナルで一度だけ確定し、勝利後会話は演出だけを完了させる。会話の再開やリロードで報酬が二重にならないようにする。

## 共通イベントフロー

### 初回接触

1. プリズムが反応し、大精霊が姿を現す。
2. 大精霊は主人公たちの属性知識ではなく、ここまで力をどう使ってきたかを短く問う。
3. 選択肢:
   - `試練を受ける`
   - `今は退く`
4. 退いた場合、戦闘も状態消費も起こさず、同じ場所から再選択できる。

### 敗北後の再接触

- 初回説明は繰り返さない。
- 大精霊は敗北を嘲笑しない。
- 属性ごとに「前回の戦いを見ていた」ことが分かる短い台詞へ変える。
- 選択肢は同じく戦う/退く。

### 勝利後

1. 戦闘結果をコミットする。
2. フィールドへ戻し、プリズム前で勝利後イベントを再開する。
3. 大精霊が一行を認め、該当属性の加護が全員へ宿る。
4. 属性結晶片の取得を表示する。
5. 6個目でなければイベント終了。

### 6個目の加護

1. 最後の大精霊の光が他の五つの加護へ呼応する。
2. 六つの光がプリズムの上で交差する。
3. 光の神リュシオンが、既存の正史を早出ししない範囲で現れる。
4. 「力を集めたから」ではなく、六つの異なる力を受け止めてきたことを認める。
5. item ID `701008` を一度だけ授与する。
6. 深淵王戦で何かが起こることは示唆してよいが、具体的な攻略説明はシステム文へ分離する。

## 属性ごとの会話方向

最終台詞は承認後に作成する。全精霊を同じ丁寧語・同じ試験官口調にしない。

### 火の大精霊

- 気質: 直截、短気ではなく潔い。
- 問うこと: 怒りや力を、守るために止められるか。
- 敗北後: 勢いだけでは火に呑まれると指摘。
- 勝利後: 熱を振るうだけでなく、抱えて進んだことを認める。

### 風の大精霊

- 気質: 軽やかで距離を測る。言葉が少し先へ逃げる。
- 問うこと: 変化を恐れず、仲間の速度に合わせられるか。
- 敗北後: 一人だけ先へ出た動きを見抜く。
- 勝利後: 留まる者を置き去りにしなかったことを認める。

### 水の大精霊

- 気質: 静かだが甘くない。
- 問うこと: 傷を受けても形を変えて進めるか。
- 敗北後: 力を受け止める余地がなかったと告げる。
- 勝利後: 折れずに流れを作り直したことを認める。

### 雷の大精霊

- 気質: 決断が速く、返答を待たない。
- 問うこと: 一瞬の判断を仲間の命へ結べるか。
- 敗北後: 迷いが一拍遅れたことを指摘。
- 勝利後: 速さを独走でなく連携へ使ったことを認める。

### 光の大精霊

- 気質: 厳格。正しさを自称しない。
- 問うこと: 自分の正義で他者を焼かないか。
- 敗北後: 眩しさで見えなくなったものを問う。
- 勝利後: 見たくない傷にも目を向けたことを認める。

### 闇の大精霊

- 気質: 静かで皮肉が少しある。悪を名乗らない。
- 問うこと: 恐れや憎しみを消さずに抱えられるか。
- 敗北後: 闇から目を逸らした瞬間を示す。
- 勝利後: 闇を否定せず、支配もされなかったことを認める。

## リュシオン登場の制約

- 王国軍と深淵の全真相を説明しない。
- 主人公を予定調和の「選ばれし者」と断定しない。
- 六属性を単なる鍵集めとして説明しない。
- 既存の光宮殿・アゼルガラグ第二形態でのリュシオン演出より強すぎる神託にしない。
- 授与後のシステム文で「深淵王との戦いで所持効果が発動する」とだけ案内する。

## 戦闘・保存仕様

- 戦う選択後に、現在の `fixedTrialElement`、報酬ID、必要属性一覧を戦闘スナップショットへ保存する。
- 敗北時は `lostOnce` と試行回数だけを保存し、加護・結晶片・完了品は付与しない。
- 勝利時は同一戦闘IDで一度だけ加護・結晶片・六属性完了判定を確定する。
- 勝利後会話中のリロードでは、報酬を再付与せず会話を再開する。
- 六属性目の勝利結果とリュシオン授与イベントを分離し、どちらか一方だけ保存された状態から復元できるようにする。
- 既に六属性加護取得済みのセーブには、再戦を要求しない互換イベントを用意する。未所持ならitem ID701008のみ一度授与し、必要なら短縮版リュシオンイベントを再生する。

## UI

- プリズム上でアクションボタンを表示する。
- 初回/再戦とも、会話終了後に明示選択肢を出す。
- 戦闘開始ボタンの二重押下を防ぐ。
- 勝利後会話は戦闘リザルトのスキップ対象外。

## 承認が必要な項目

1. item ID701008の表示名を、既存の「オクタプリズマ」からユーザー指定の「オクタプリズム」へ統一するか。
2. 六属性の大精霊は現行名のままにするか、個別名を与えるか。
3. 六個目の加護がどの属性でも、同じリュシオン授与イベントへ接続する構成でよいか。
4. 既に六属性を取得済みのセーブへ、短縮版授与イベントを初回のみ再生するか、アイテム補填だけにするか。
