# 焼け焦げたペンダント共鳴・オクタプリズマ授与イベント

作成日: 2026-08-04  
対象スクリプト: `ABYSS_SPIRIT_TRIAL_ALL_COMPLETE`  
実装状態: **2026-08-04 ユーザー承認済み・story.js反映済み。**

## 1. 目的

六属性の大精霊に認められ、六つの結晶片が揃った時、主人公がゲーム開始時から所持している「焼け焦げたペンダント」が共鳴する。
混沌の汚染が解けて「光結晶のペンダント」へ変化し、その光を通じてリュシオンの声が届き、「オクタプリズマ」が生み出される。

主人公の故郷、母、村の神器だったことは、この場面では直接説明しない。

## 2. 現行

```text
システム：六つの加護が呼応し、色の異なる光が一つの輪を描いた。
光の神：火、水、風、雷、光、闇。
　　　　異なる力を従えるのではなく、共に歩む者よ。
光の神：深淵の混沌へ抗う時、この結晶が六精霊の道を繋ぐでしょう。
　　　　オクタプリズマを受け取りなさい。
システム：六色の光が結晶となり、静かに手の中へ降りた。
```

## 3. 承認済み本文

```text
システム：六つの結晶片が一斉に震え、胸元の焼け焦げたペンダントが熱を帯びた。

システム：黒く焼けた表面から、細かな煤がほどけていく。
　　　　　その奥で、懐かしい温もりに似た光が脈打った。

リュシオン：……ようやく、届きました。

リュシオン：六つの加護が、その小さな光を呼び覚ましたのです。
　　　　　　あなたが失わずにいたものへ、私の声もまた届く。

リュシオン：深淵の混沌へ抗う時、その光は六精霊の道を結びます。
　　　　　　受け取りなさい――オクタプリズマを。

システム：焼け焦げたペンダントは、澄んだ光を宿す結晶へと姿を変えた。
　　　　　光結晶のペンダントと、オクタプリズマを手に入れた！
```

## 4. 演出上の意図

- ペンダントが母から託されたことは明言しない。
- 故郷が光の神を信仰していたことは明言しない。
- 「懐かしい温もり」「あなたが失わずにいたもの」で、主人公の過去との繋がりだけを薄く残す。
- リュシオンは全設定を説明せず、ペンダントが長く光を保っていた事実だけを示唆する。
- 入手物はシステム文で明確に伝える。

## 5. 実装条件

- 会話完了後の専用アクションで、オクタプリズマ付与とペンダント変化を原子的に確定する。
- 保存失敗時は、オクタプリズマ、両ペンダント、授与済みフラグをすべて元に戻す。
- 再開・再処理時も、焼け焦げたペンダントと光結晶のペンダントを同時所持させない。
- 既にオクタプリズマ所持済みの旧セーブは、起動時移行で光結晶のペンダントを所持するため、授与イベントを再生しない。
