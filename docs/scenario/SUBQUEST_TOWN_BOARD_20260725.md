# 町・拠点の軽微依頼 追加仕様

作成日: 2026-07-25

リュミナ村を除く主要な町・拠点へ、討伐1件と素材交換1件を追加する。既存の加入クエストやメイン進行を変更せず、各地クリア後に依頼掲示板が出現する。

| 設置場所 | 解放条件 | 討伐依頼 | 素材交換依頼 |
|---|---|---|---|
| 炎の里イグニシア | `fireVillageCleared` | 炉辺の小討伐 | 炉材の仕立て直し |
| 風の集落カザリア | `windVillageCleared` | 枝道の魔物払い | 風織りの素材束 |
| 水上都市リヴァリア | `waterCityCleared` | 水路灯の警備 | 水薬の濃縮交換 |
| 大灯台 | `bigTowerCleared` | 灯台下層の掃討 | 高所補修材の調達 |
| ライザーク要塞 | `thunderFortCleared` | 残雷区画の巡回 | 要塞部材の再精製 |
| 光の宮殿グランプリズマ | `lightPalaceCleared` | 白光回廊の浄掃 | 聖光素材の昇華 |
| 魔王城ガルヴァニア | `darkCastleCleared` | 城外縁の魔掃戦 | 魔城炉の高位精錬 |
| 深淵の魔窟 外縁 | `abyssFirstEntered` | 外縁裂界の鎮圧 | 深淵素材の定着 |

## 共通動作

- 掲示板を調べると2件を一覧表示する。
- 状態は「受注可能」「受注中」「報告可能」「達成済み」で表示する。
- 討伐数は既存の `noteQuestKills` で加算する。
- 素材交換は報告時に必要素材を消費する。
- 交換報酬は、納品素材より上のランクの素材を基本とする。
- 既存のクエスト記録、詳細モーダル、セーブデータ形式を利用する。
