# PRISMA ABYSS Phase2R 実装報告

作成日: 2026-08-04  
基準: Phase2P/Q適用済みソース + ユーザー提供 `achievements.js`

## 1. 実装概要

### 焼け焦げたペンダント

正式アイテムマスターへ以下を追加した。

- `701009`: 焼け焦げたペンダント
- `701010`: 光結晶のペンダント

どちらも貴重品であり、売却・使用・店頭入手・深淵ドロップの対象外とした。

### 新規ゲーム

新規ゲームの正式初期データとフォールバック初期データへ、焼け焦げたペンダント×1を追加した。

### 旧セーブ補填

一度限りの互換移行 `20260804_pendantOctaprismV1` を追加した。

- オクタプリズマ未所持: 焼け焦げたペンダント×1を補填。
- オクタプリズマ所持済み: 光結晶のペンダント×1を補填。
- 両ペンダントが同時に残らないよう、物語状態に合わない側を除去。
- 同じ移行を再実行しても個数を増やさない。
- 互換移行共通処理により、保存失敗時はアイテム変更と移行済み記録を復元。

### 六属性完了イベント

六属性大精霊試練の完了イベントを、ペンダント共鳴を中心とする承認済み会話へ置換した。

会話後の専用処理 `grantOctaprismFromPendant()` で、以下を一つの原子的保存として確定する。

- 焼け焦げたペンダントを除去。
- 光結晶のペンダントを1個所持。
- オクタプリズマを1個所持。
- 六属性完了・授与済みフラグを確定。
- 試練イベント状態を完了へ統一。

再処理時も光結晶のペンダントとオクタプリズマを増殖させない。保存失敗時はアイテム・フラグ・イベント状態をすべて復元する。

承認済みシナリオ正本:

- `docs/scenario/30_PENDANT_OCTAPRISM_RESONANCE_APPROVED_20260804.md`

### セーブ・ロード画面の並行修正

ユーザー確認画像を基に、次を追加修正した。

- 上部の「オートセーブ1枠／手動セーブ9枠」表示を削除。
- 通常時のオートセーブ説明文を削除。
- 通常時のロード説明文を削除。
- 保存領域が利用できない場合など、操作に必要な警告だけ表示。
- スロット内プレイ時間の幅制限を見直し、右端の欠けを修正。

### プレイ時間

プレイ時間変換を、ミリ秒を秒へ変換してから切り捨てる順へ修正した。

- セーブ・ロード一覧: `hhhh:mm:ss`
- 戦歴メニュー: `hhhh:mm:ss`
- 小数秒・ミリ秒は表示しない。
- 最大表示は既存仕様どおり `9999:59:59`。
