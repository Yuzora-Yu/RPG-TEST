# PRISMA ABYSS 実装フェーズ2F報告

作成日: 2026-08-03  
対象: Phase2E適用済みソース

## 1. 本フェーズの範囲

本フェーズでは、裏ボス「ギルガメッシュ」の基礎能力、周回強化、勝利時報酬、災厄の楔消費、仲間加入・LB処理を再設計した。

実装済み:

- ギルガメッシュの基礎能力を深淵300階付近の想定戦力向けに強化
- 過去討伐数1回につき主要能力+20%の専用周回補正
- 一般の深層ボス強化・物語ボス倍率との重複防止
- EXP・GOLDを旧値の10分の1へ変更
- 勝利確定時だけ災厄の楔を1個消費
- 10,000 GEMとEX装備確定報酬を維持
- 転生の実と同率・独立抽選で合成の壺を追加
- 初回5%、以後は完了討伐数×5%で仲間加入判定
- 既加入時は通常の仲間モンスターLB処理を実行
- ギルガメッシュ専用の「全特化型」仲間成長マスターを追加
- 勝利結果ジャーナルへの一度限り記録
- 同一戦闘結果の二重適用防止

## 3. 討伐回数による強化

戦闘開始時点の過去討伐数を使用する。

```text
能力倍率 = 1 + 過去討伐数 × 0.20
```

| 挑戦 | 過去討伐数 | 能力倍率 |
|---:|---:|---:|
| 初回 | 0 | 1.00倍 |
| 2戦目 | 1 | 1.20倍 |
| 3戦目 | 2 | 1.40倍 |
| 6戦目 | 5 | 2.00倍 |

対象はHP、MP、攻撃、防御、速さ、魔力、魔防である。

固定IDで開始する戦闘にも専用倍率を適用し、以下は重複させない。

- 深淵101階以降の一般ボス強化
- 物語ボス倍率
- 試練用敵倍率

生成済み敵の保存データには、開始時討伐数と専用倍率を保存する。戦闘再開時は保存済み能力を復元し、倍率を再適用しない。

## 4. 災厄の楔と勝利結果

災厄の楔（ID 98）は、従来どおり挑戦開始時に所持確認を行う。

消費タイミングを次へ統一した。

- 勝利結果を確定するトランザクション内で1個消費
- 敗北では消費しない
- 逃走では消費しない
- 戦闘中断・保存失敗時は消費をロールバック
- 同じ結果ジャーナルを再読込しても再消費しない

楔消費、報酬、仲間加入・LB判定は、同じ勝利確定処理 `applySpecialBossVictoryOutcome()` で処理する。

## 5. 報酬

### 確定報酬

- 10,000 GEM
- EX相当装備1個

EX装備は従来仕様を維持し、次の処理を行う。

- +3
- オプション最低候補: UR・EX
- 装備価値3倍
- 名称先頭に `【EX】`

### 個別ドロップ

`monsters.js` の既存ドロップ設定を使用する。

- 通常: スキルのたね 50%
- レア: 転生の実 10%

合成の壺は、転生の実と同じ10%および同じレアドロップ補正を使い、転生の実とは独立して抽選する。

## 6. 仲間加入とLB

加入率は、今回の勝利を含む完了討伐数を使用する。

```text
加入率 = min(100%, 完了討伐数 × 5%)
```

| 完了討伐数 | 加入率 |
|---:|---:|
| 1 | 5% |
| 2 | 10% |
| 5 | 25% |
| 10 | 50% |
| 20以上 | 100% |

加入成功時:

- 未加入なら仲間モンスターとして追加
- 既加入なら同じ個体のLBを1上昇する通常処理を実行
- LBの共通最大値・試練解放条件は既存の仲間共通ルールを維持

加入・LB結果も勝利結果ジャーナルへ保存され、同じ戦闘結果で二重実行されない。

仲間モンスター成長型マスターをスキーマ3へ更新し、25番目の正式成長型 `ALL_SPECIAL` を追加した。

| 成長基礎 | 全特化型 | ゼノン |
|---|---:|---:|
| HP | 142 | 118 |
| MP | 50 | 41 |
| 攻撃 | 146 | 122 |
| 防御 | 90 | 72 |
| 速さ | 76 | 61 |
| 魔力 | 142 | 118 |
| 魔防 | 114 | 95 |

すべての能力でゼノンを上回る固定成長型である。

- ギルガメッシュの `allyGrowthType` を `ALL_SPECIAL` に変更
- 通常の成長予算正規化を行わず、マスター記載値をそのまま使用
- 既に仲間のギルガメッシュも、ロード時の成長型スキーマ移行で新しい成長基礎へ更新
- 現在レベル、現在能力、スキル、特性、LBは変更しない

## 8. 戦闘結果ジャーナル

勝利結果には `specialBossOutcome` を保存する。

主な記録項目:

- 戦闘ID
- モンスターID
- 完了討伐数
- 適用能力倍率
- 楔消費結果
- GEM量
- 確定装備名
- 転生の実・通常品・合成の壺の結果
- 加入率
- 加入成功の有無
- 既加入・LB上昇の有無

同じ戦闘ID・モンスターIDで適用済みの場合、結果を再利用し、副作用を再実行しない。

## 10. 検証

専用テストで次を確認した。

- 初回1.00倍、2戦目1.20倍、3戦目1.40倍
- 固定ID戦闘でも専用倍率を使用
- 一般深層・物語ボス倍率と重複しない
- 保存・復元時に倍率を二重適用しない
- 加入率5%・10%・50%・100%
- 勝利時だけ楔を1個消費する確定関数
- 10,000 GEMとEX装備
- 転生の実と合成の壺の同率独立抽選
- 未加入時の加入
- 既加入時のLB上昇
- 同一戦闘IDで報酬・楔・加入を二重適用しない
- 楔がない不正な勝利確定を拒否
- 全特化型がゼノンを全能力で上回る
- 既存のRank120調整テストとの整合

既存の全回帰テストにも合格した。

### 検証上の制約

実行環境の制限により、ブラウザ上での実際の戦闘操作・体感難易度確認は行っていない。

実機では次を重点確認すること。

1. 初回ギルガメッシュの被ダメージ・与ダメージ
2. 転生3～5回、Lv100前後での戦闘時間
3. 敗北後に楔が残ること
4. 勝利後に楔が1個だけ減ること
5. 2戦目以降の能力上昇
6. 加入成功後、再加入成功でLBが上がること
7. 勝利演出中の再読込で報酬が二重にならないこと
