# Phase2H 実装記録 2026-08-03

## 実装範囲

### 六属性プリズム・大精霊イベント

- `abyss_content.js`へ六属性試練の正式マスターを追加。
- `story.js`へ各属性の初回、敗北後、勝利後の仮会話を追加。
- 初回・再挑戦会話の後に「試練を受ける／退く」選択肢を追加。
- `story_logic.js`へ試練開始、勝利後完了、オクタプリズマ授与確定の専用アクションを追加。
- `main.js`のプリズム接触を、直接戦闘開始からStoryManager経由へ変更。
- 属性ごとに `untouched / challenged / lost / victory / completed` を保存。
- 敗北結果で再挑戦状態を保存。
- 勝利結果で加護と属性結晶片を確定し、戦後会話をキューへ保存。
- 六属性目は光の神の共通イベントからitem ID `701008`を一度だけ授与。
- 旧六加護取得済みセーブを再戦なしで補完。
- 「授与演出済み」だけが残りオクタプリズマ本体を欠く旧セーブも、授与イベントへ戻して救済。
- 試練勝敗結果を戦闘結果ジャーナルへ追加。

通常起動時のボスID・結晶片IDは `ABYSS_REGION_CONTENT.spiritTrials`を正本とする。`story.js`単体を読むエディタ・検証器では、同一IDの静的フォールバックだけを使用する。

台詞はユーザー許可に基づく先行仮稿。イベントID・保存キー・戦闘結果処理を維持したまま、承認後に本文のみ差し替えられる。

### オクタプリズマ × アゼルガラグ

- item ID `701008`の名称は既存「オクタプリズマ」を維持。
- 手動使用を廃止し、所持時自動発動へ変更。
- アゼルガラグ本編の第一形態 `302100`、第二形態 `302101`のみ対象。訓練所は対象外。
- 戦闘開始時の所持判定を `battle.octaprismState.possessedAtBattleStart`へ固定し、再読込・形態移行時に現在所持数を再判定しない。
- 主人公の戦闘中混沌耐性を最低90%へ補正。
- 編成オーラ再計算で通常耐性へ戻る経路でも、直後に90%下限を再適用。
- 毎ターン開始時50%で六精霊支援。
- 同一ターンの実行経路へ戻った場合は、保存済みターン結果を再利用して二重適用を防止。
- 直前と同じ精霊は次回抽選候補から外す。
- 支援はログと属性画面エフェクトだけで、会話待ち・カットイン停止なし。
- 火、水、風、雷、光、闇の効果を正式マスター化。
- 雷の1ターン守備低下と、闇の2ターン全能力低下を別枠化。雷分だけが1ターンで切れ、闇分は残る。
- 第一・第二形態で状態と支援履歴を継承。
- 旧手動使用済みの途中戦闘は新状態へ互換変換。

## 六精霊支援の初期値

| 属性 | 効果 |
|---|---|
| 火 | 敵全体へ最大HP4%。第一形態上限4000、第二形態上限6000 |
| 水 | 味方全体の最大MP15%回復 |
| 風 | 生存者全体の最大HP18%回復 |
| 雷 | 敵全体へ最大HP3%。第一形態上限3200、第二形態上限4800。守備力15%低下、1ターン |
| 光 | 味方全体の全属性耐性+50%、1ターン |
| 闇 | 敵全体の攻・防・速・魔・魔防を10%低下、2ターン |

火・雷は敵HPを1で止めず、支援による撃破と通常の形態移行を許可する。

## 専用テスト

```bash

```

次を検証する。

- 六属性分の会話・イベント・正式マスター。
- 初回、敗北後、勝利後、旧セーブ補填の分岐。
- 演出済みフラグだけ残ったオクタプリズマ欠損セーブの救済。
- オクタプリズマが手動使用不可であること。
- 未所持、対象外ボス、訓練所では発動しないこと。
- 戦闘開始時所持スナップショットを途中で変更しないこと。
- 混沌耐性89→90、120→120、編成オーラ再計算後の90%再適用。
- 50%抽選境界、同一ターン二重適用防止、連続属性回避。
- 六属性効果、画面FX呼出し、雷と闇の守備低下の別枠処理。
- 第一形態から第二形態への状態継承。
- 試練の勝敗状態と結果ジャーナル接続。
- 同一勝利結果で加護・結晶片を二重付与しないこと。
- 六属性目の戦闘結果でオクタプリズマを先行付与しないこと。
