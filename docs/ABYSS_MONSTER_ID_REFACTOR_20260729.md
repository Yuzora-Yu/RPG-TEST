# 深淵追加モンスター ID再編報告

- 通常敵55体は独立配列を廃止し、Rank帯ごとの `MONSTER_BANDS_1_200` に統合。
- 深淵ストーリーボス16体は `302000～302999` に統合。
- 六属性精霊6体は試練用ボス `502000～503000` に統合。
- `ABYSS_REGION_MONSTERS` と `FIXED_ABYSS_REGION_BOSSES` は廃止。
- モンスター画像名、MAP、イベント、戦闘、図鑑、検証マニフェストを新IDへ追従。
- セーブデータの `monsterIdSchemaVersion` を4へ更新し、チェックポイント3の旧IDから自動移行。
