### 3.2 お知らせ詳細モーダル

`menus_news_detail.js` と `modern-polish.css` を変更した。

構造:

```text
ゲームコンテナ内オーバーレイ
└─ ダイアログ
   ├─ ヘッダー（固定）
   ├─ 本文（縦スクロール）
   └─ フッター（固定）
```

対応内容:

- `#game-container` 内へ配置し、ゲーム表示領域を上限にした。
- 外枠をflex縦構造にした。
- 本文へ `flex:1`、`min-height:0`、`overflow-y:auto` を設定した。
- ヘッダーと閉じるボタンをスクロール対象外にした。
- safe-areaを考慮した余白を追加した。
- 横画面かつ低い表示領域向けの調整を追加した。
- 長い英数字・URL相当の文字列を折り返すようにした。
- タイトル・本文をHTMLエスケープした。
- 存在しないお知らせIDでも例外を起こさないようにした。

## 4. 可変長モーダル横断監査

今回の改修対象はお知らせだけとし、他画面は次の完成単位へ分離した。

| 画面 | 状況 | 判定・理由 | 次対応 |
|---|---|---|---|
| お知らせ詳細 | 修正済み | 固定ヘッダー・本文スクロール・固定フッター | 実機確認 |
| 仲間詳細 | 既存対応あり | `.scroll-area`、`flex:1`、`min-height:0`、本文スクロール | 回転試験のみ |
| チュートリアル | 既存対応あり | 専用パネル、本文スクロール、固定フッター | 実機確認 |
| 施設・ショップ | 既存対応あり | 外枠max-height、本文スクロール、閉じるボタン固定 | 各施設回帰 |
| 鍛冶 | 既存対応あり | スクロール領域と下部操作が分離 | 実機確認 |
| 実績 | 比較的安全 | サブ画面の共通スクロールと固定下部パネルを利用 | 長文実績データで確認 |
| スキル詳細 | 要修正・高 | body直下固定モーダル。カードに高さ上限・本文スクロールなし | 次回最優先 |
| 特性詳細 | 要修正・高 | 詳細・再抽選結果とも外枠高さ上限なし | 次回最優先 |
| 図鑑の特性詳細 | 要修正・高 | カード高さ上限・本文スクロールなし | 共通詳細シェルへ統合候補 |
| 汎用メッセージ・確認 | 要修正・高 | テキスト領域に上限・スクロールなし。選択肢増加時に操作域が押し出され得る | 共通ダイアログ改修 |
| クエスト詳細 | 要修正・中 | 詳細カード自体はスクロールするが、カード上限と外側ボタンを合算すると低画面で超過し得る | ヘッダー/本文/フッター分離 |
| 戦闘作戦選択 | 要改善・中 | 全カードスクロールで閉じるボタンも流れる | フッター固定化 |
| シナリオ二択 | 要実機確認・中 | 300px上限と全体スクロールはあるが、本文とボタンが同一スクロール領域 | 小画面・長文選択肢試験 |

次回は、個別のインラインCSSを継ぎ足すのではなく、スキル・特性・図鑑特性・汎用確認で共有可能なモーダルシェルを先に定義する。
