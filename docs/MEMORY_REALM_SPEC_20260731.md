# 追憶の魔境 実装仕様（2026-07-31）

## 入口と移動
- ワールドマップ座標: `x:9, y:59`
- 本編深淵とは独立し、入場・挑戦・セーブ再開によって `abyssFirstEntered`、本編ストーリー目的、深淵挑戦回数を変更しない。内部ダンジョン処理で `area=ABYSS` を共用しても、UIと進行判定では追憶モードを除外する。
- ダンジョン名: 追憶の魔境
- 解放フラグなし。船で座標へ到達できれば進入可能。
- スカイプリズム登録順は「最果ての祠」の直前。初回到達時に発見登録する。
- 入場・脱出・全滅後の再挑戦は必ず1階から。

## 階層と敵強化
- 全30階。1階はRank91相当、以後1階ごとに+1、30階はRank120相当。
- 通常階は地上ダンジョンのモチーフを抽選し、マップチップ・戦闘背景・生息モンスターを同じ出典へ揃える。
- 対象通常モンスターはRank1～85。生息地を持たない同Rank帯のレアモンスターも低確率で出現対象に含める。
- `リトルメイジ(503)`、`アクアリリィ(507)`、`ライトリリィ(604)`、`スカウトデビル(752)`、`ヒールフェアリー(654)`は、抽選されたモチーフを問わず全エリア共通の出現候補とする。
- 属性と物理／魔法傾向に合わせ、Rank91～120帯向けのスキルへ戦闘生成時に再編する。
- 指定ストーリーボスは通常敵枠にも低確率で出現できる。通常敵枠では同Rank帯通常モンスターの基礎値へ正規化し、HP・報酬をボス値のまま使わない。
- 撃破時の仲間化は、加入可能な敵1体ごとに独立して1%抽選する。指定ボスも対象で、1戦中に複数体が成功する場合がある。
- 装備・通常アイテムの抽選Rankは強化後Rankを使用する。

## 休憩所
- 10階: Rank100相当の道具屋・武器屋・防具屋、宿屋50,000G、鍛冶屋、錬金屋。
- 20階: Rank110相当の道具屋・武器屋・防具屋、宿屋100,000G、鍛冶屋、錬金屋。
- 休憩階はランダムエンカウントなし。階段から次階へ進む。

## 30階
- ボス候補ID: `301010,301020,301030,301040,301050,301061,301070,301080,301081,301082,303201,303202,303203,303204,303205,303206,303207,303208`
- `301100` 魔王ゼノンは、30階ボスおよび通常階のボス混入候補から除外する。
- ボスはRank120相当。30階も抽選された地上ダンジョンの戦闘背景を維持する。
- 討伐後、毎周回取得可能な宝箱を配置する。
  - Rank120相当レア装備: 3個
  - ランダム特性書: 1個
  - ランダムスキル書: 1個
- 最奥に回復の泉と地上帰還ゲートを配置。
- 初回限定報酬なし。踏破実績は報酬なしで自動記録する。

## 併記修正
- 海底神殿3階のMAP表示ボスをモンスターID `301030` に固定。
- スキル書のname/descはitems.jsの固定文言ではなく、skillIdからSKILLS_DATAを参照して動的生成する。

## 戦闘表示の共通仕様
- 敵名の末尾に付く識別文字 `A/B/C...` は、同じ表示名の敵が同一戦闘に複数いる場合だけ付与する。混成編成では各モンスター名に識別文字を付けない。
