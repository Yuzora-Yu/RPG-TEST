# ランダム深淵 階層再編・実績／戦歴拡張 v2

## 1. 設計方針

深淵の階層は、以下の3モードと2種類の階層値を明確に分離しています。

- `story`：従来の物語深淵1～100階。表示階層とバランス階層は同じです。
- `random`：旧101階以降を新1階から表示します。バランス階層は「表示階層+100」です。
- `guild`：ギルド依頼専用のランダムダンジョンです。物語／ランダム深淵の到達記録を更新しません。

共通定義は `dungeon.js` の `ABYSS_FLOOR_RULES` に集約しました。個別処理で100を足し引きする設計にはしていません。

| 新しい表示 | 内部バランス | 意味 |
|---:|---:|---|
| ランダム深淵1階 | 旧101階 | 全背景・旧101階相当の敵、宝箱、ドロップ |
| ランダム深淵100階 | 旧200階 | 旧200階ボス背景・旧200階相当報酬 |
| ランダム深淵101階 | 旧201階 | 深層生成、真・装備、ランダムボス抽選帯 |

ボス部屋は従来どおり10階刻みです。ランダムボスへ切り替わる判定帯は新101階以降ですが、通常進行で最初に到達する10階刻みのランダムボス部屋は110階です。これは旧仕様の「201階以降の10階刻みボス」を100階分シフトした結果であり、ボス階周期自体は変更していません。

## 2. 影響範囲

以下を表示階層／バランス階層／モードの共通ルールへ接続しました。

- 通常モンスター選出、レアモンスター抽選、能力補正
- ボス編成、深層ランダムボス、ボス戦背景
- 通常宝箱、レア宝箱、アイテム、Gold、実・種、装備品質
- ミミックの解禁階と種類
- 溶岩、浸水、迷路、宝物庫、外観テーマ抽選
- 試練の天使、冒険者、回復の泉、鍵扉、鍵宝箱
- 深淵の裂け目の対象階層、敵能力、報酬
- 真・装備の開始階
- 宿屋の転送扉と転送料金
- 物語目的表示、深淵到達実績、限界突破用の深淵進行値
- 固定・自動生成ギルド依頼の階層、解放条件、討伐記録
- Service Workerと全データキャッシュの更新名

## 3. 物語深淵とランダム深淵

物語深淵1～100階は、既存のボスイベント・フラグ・演出を維持しています。物語100階のエピローグ完了後に `abyssRandomUnlocked` を設定し、ランダム深淵を解放します。

深淵メニューと宿屋の転送扉では、物語深淵／ランダム深淵を選択できます。最高到達階と挑戦回数も別々に記録します。

## 4. セーブデータ移行

`system.abyssFloorSchemaVersion = 2` として一度だけ移行します。

- 旧最高到達100階まで：物語深淵の最高到達へ移行
- 旧最高到達101階以上：物語100階踏破＋ランダム深淵「旧最高到達-100階」へ移行
- 旧101階以上に滞在中：現在表示階層を100階分減算し、モードを`random`へ移行
- 戦闘中の表示階層、ボス情報、裂け目、特殊オブジェクト、鍵情報も移行
- 旧乱数キー `ABYSS:Fxxx` は `ABYSS:story:Fxxx` または `ABYSS:random:Fxxx` へ移行
- 生成済みマップや宝箱状態は保持し、進行・取得状態を失わせません
- 旧挑戦回数は物語／ランダムへ正確に分離できない場合、合計を維持しつつ「旧仕様の未分類挑戦」として記録します

過去の錬金・鍛冶操作回数はセーブから正確に復元できないため、推測加算は行いません。更新後に確定した操作から正確に累積します。

## 5. 実績・戦歴

以下の永続カウンタを追加し、操作の確定時だけ加算します。

- 通常クエストクリア数
- ギルド依頼クリア数
- 錬金回数、錬成アイテム数
- 鍛冶回数、装備合成回数
- 精錬の挑戦数／成功数
- 強化の挑戦数／成功数
- 戦闘勝利数、宝箱開封数
- 物語／ランダム深淵の最高到達階・挑戦回数
- 冒険者ランク

実績には、通常クエスト、ギルド依頼、冒険者ランク、錬金、鍛冶、戦闘勝利、物語深淵100階、再編後ランダム深淵の到達目標を追加しました。

既存実績ID 301～305は、旧セーブの解除・報酬受取状態を壊さないよう、旧来の到達地点と同じ意味を維持しています。追加のランダム深淵到達実績には新規IDを使用しています。

## 6. story-ui-stage

`modern-polish.css` で `#story-ui-overlay` と `.story-ui-stage` の幅・高さを親要素の100%へ統一し、残っていた `max-width:450px` 相当の制限を無効化しました。`100vw`は使用せず、ゲームコンテナをはみ出さない設計です。

## 7. 適用方法

ZIP内の階層を維持したまま、プロジェクトルートへ上書きしてください。ZIPには変更・追加ファイルのみを収録しています。画像ファイルの変更はありません。
