# PRISMA ABYSS 実装フェーズ2A報告

作成日: 2026-08-03  
適用前提: `PRISMA_ABYSS_phase1_growth_nursery_20260803.zip` 適用済みソース

## 1. このフェーズの範囲

本フェーズでは、Phase1の成長特性に関するユーザー補正を反映し、装備ランダム特性を武器種別に正式管理した。
あわせて、比較的独立して実装できるクリア後施設と、ふるびたコイン交換の再編を行った。

実装済み:

- 固定付与された装備の成長特性を、永続成長と必要経験値へ再反映
- 「大器晩成」「武の極み」「魔の極み」を装備のランダム特性抽選から除外
- 武器共通・武器種別のランダム特性候補マスターを新設
- 全装備生成経路を共通の特性候補処理へ接続
- エピローグ閲覧後に利用できるレガシオンのカジノを追加
- エピローグ閲覧後に利用できるレガシオン技法書店を追加
- 技法書店へ109種類の技法書を設定
- 「ちいさなメダル」をプレイヤー表示上「ふるびたコイン」へ統一
- 魔法の小舟を交換景品から削除
- 回復品、Rank50・Rank90攻撃道具、災厄の楔の交換枚数を変更
- レプリカ5種をRank70相当の正式な特殊装備マスターへ移行
- ロンリーメタル・メタルロードへの通常装備名称変更
- 同日1レコードで簡潔に管理する `news.js` 更新方針を明文化
- 更新履歴用バリデーターと、今回の施設・交換・装備特性用回帰テストを追加

このフェーズでは、Rank120以降の敵能力・経験値、ギルド依頼迷宮、ランダム迷宮、深淵101階以降、ギルガメッシュ、属性特殊装備クエスト、特性書50クエストには未着手。

## 2. 装備特性と成長処理

### 2.1 固定装備特性の扱い

Phase1で行った「装備特性を永続成長から除外する」変更を取り消した。

現在は、本人特性と装備特性を合算する既存の `PassiveSkill.getSumValue()` を使用し、固定付与された以下の特性がレベルアップへ影響する。

- 大器晩成
- 武の極み
- 魔の極み

大器晩成が装備に固定付与されている場合は、必要経験値増加も反映する。

### 2.2 ランダム付与禁止

以下の特性IDは、武器・防具を問わず装備のランダム特性候補から除外した。

| ID | 特性 |
|---:|---|
| 58 | 大器晩成 |
| 59 | 武の極み |
| 60 | 魔の極み |

正式な装備マスターレコードの `traits` に固定設定した場合は、従来どおり装備効果として機能する。

### 2.3 武器ランダム特性候補

`passiveSkill.js` に次を正式定義した。

- `EQUIPMENT_RANDOM_FORBIDDEN_TRAIT_IDS`
- `WEAPON_RANDOM_TRAIT_POOLS`
- `getEquipmentTraitCandidateIds()`

武器共通候補:

- 底力
- 急所狙い
- 追い討ち
- 連携
- 悪魔ばらい
- 獣狩り
- メカニック
- 竜殺し
- 火・水・風・雷・光・闇・混沌の扱い

武器種別候補:

| 武器 | 専用候補 |
|---|---|
| 剣 | 剣、武術、息吹、反撃、二刀流 |
| 槍 | 槍、武術、息吹、先制、両手持ち |
| 斧 | 斧、武術、息吹、反撃、両手持ち |
| 短剣 | 短剣、武術、魔術相当、息吹、先制、反撃、暗殺術、二刀流 |
| 弓 | 弓、鷹の目、武術、魔術相当、息吹、両手持ち |
| 杖 | 杖、魔術相当、息吹、理力の壁 |

現行特性マスターではユーザー指定の「魔術」に相当するID 11の名称が「呪文」のため、内部ID 11を候補として使用している。特性名称そのものは本フェーズでは変更していない。

### 2.4 抽選処理

全装備生成経路で、生成中の装備を `generateEquipmentTraits()` へ渡すよう変更した。

- ランダム装備生成
- 真・装備生成
- EID指定装備の+3生成
- ショップ装備生成

固定特性と同じIDはランダムで重複付与しない。
ランダム候補は重複なしで抽選する。

## 3. クリア後施設

### 3.1 解放条件

カジノと技法書店は、以下の正式進行フラグを使用する。

```text
abyssEpilogueSeen
```

ラスボス撃破だけでは解放されず、エピローグ閲覧後に利用できる。

### 3.2 レガシオン技法書店

配置:

```text
レガシオン (32,25)
```

既存施設・モンスター育成所・格闘場予定地とは別座標で、施設床 `H` 上に配置した。

販売方式:

- 既存ショップの `itemIds` 指定方式を使用
- 販売対象を各アイテムマスターレコードへ明示
- 価格0だった販売対象には、ランクを基準とした正式な購入価格を設定
- 既存の通常ショップ自動抽選条件は変更しない

品揃え:

- 109種類
- 一般攻撃、武器技、補助、回復、属性呪文、ブレスなどを大幅追加
- 明確な終盤ボス専用・イベント専用として扱うID帯は除外

### 3.3 カジノ

配置:

```text
レガシオン (38,32)
```

既存カジノ機能を再利用し、フィールドの正式な `casino` アクションから入場する。

## 4. ふるびたコイン

### 4.1 名称

プレイヤーが見る名称を次のように変更した。

```text
ちいさなメダル → ふるびたコイン
```

対象:

- アイテムマスター
- 交換所
- フィールドアクション
- 実績
- ステータス画面
- ストーリー目標
- 施設BGM表示名
- 交換施設の画面表示

セーブ互換のため、内部のアイテムID 99、`medals`、`totalMedals` などの既存キーは維持している。

交換施設の人物・地名表示は「古銭王」とした。

### 4.2 交換景品

| 景品 | 必要枚数 |
|---|---:|
| 上やくそう×3 | 2 |
| 魔法の小瓶×5 | 2 |
| 世界樹の葉 | 4 |
| エルフの飲み薬 | 5 |
| 世界樹の雫 | 6 |
| Rank50属性攻撃道具 | 各3 |
| Rank90属性攻撃道具 | 各5 |
| 鷹眼の秘薬・幻影の秘薬 | 各5 |
| 神霊の雫 | 10 |
| レプリカ特殊装備 | 各20 |
| 災厄の楔 | 50 |

魔法の小舟は交換景品から削除した。

### 4.3 レプリカ装備

交換所内で能力値を直接組み立てる旧処理を廃止した。

`equips.js` にEID 901～905の正式レコードとして追加し、交換時は `App.createEquipById()` を使用する。

共通仕様:

- Rank70
- `noRandom: true`
- `specialEquip: true`
- ランダムドロップ用マスターとは分離
- ランダム特性なし
- 交換枚数20枚

追加装備:

- メタルロードの鎧・レプリカ
- メタルロードの盾・レプリカ
- メタルロードの兜・レプリカ
- メタルロードの剣・レプリカ
- メタルロードのブーツ・レプリカ

能力値は既存Rank70装備を基準にし、同等の基礎値へ小規模な固有効果を加えた。

### 4.4 通常装備名称

装備マスター上の名称を一括変更した。

```text
はぐれメタル → ロンリーメタル
メタルキング → メタルロード
```

ランタイム上に旧名称が残っていないことを専用テストで確認している。

### 目視確認上の制約

この実行環境ではローカルゲームをブラウザで開く目視・タップ試験を行えない。
通常ブラウザまたは実機では、特に以下を確認すること。

1. エピローグ前はカジノ・技法書店のアクションが表示されないこと
2. エピローグ後はレガシオンの各施設へ入れること
3. 技法書店の長い一覧のスクロールと購入
4. ふるびたコイン交換の表示・消費・装備入手
5. レプリカ装備の詳細表示と装備
6. +3武器、真・装備、ショップ武器のランダム特性
