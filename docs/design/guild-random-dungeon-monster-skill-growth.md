# ギルド依頼迷宮の敵強度と仲間モンスターのスキル成長

## ギルドクエスト「ランダムダンジョン探索」の敵強度

依頼生成時に、まず基準値 `power` を一度だけ計算し、その値を依頼データへ保存する。ロードのたびに変化しない。

```text
rankPower   = (ギルドランクの添字 + 1) × 22
expPower    = floor(sqrt(累積ギルドEXP) × 4)
storyPower  = storyStep × 7
floorPower  = 深淵の実質到達階
rarityPower = SSR:20 / UR:45 / EX:85

power = max(35, floor(max(rankPower, storyPower, floorPower)
                      + expPower + rarityPower))
```

ギルドランク由来の値は、G/F/E/D/C/B/A/Sの順に22/44/66/88/110/132/154/176。

### 通常敵候補

- ボス、レア、昇格試験官、特殊ボス、エスターク系を除外する。
- 依頼属性と一致する技を持つ魔物を優先する。
- 元Rankが `power × 0.18` 以上かつ `power × 1.35` 以下の個体を優先する。
- 条件に合う候補から最大16種を保存する。

### 通常敵の能力補正

```text
rarityMultiplier = SSR:1.25 / UR:1.65 / EX:2.25
progressionMultiplier = max(1, 1 + power / 400)
statMultiplier = rarityMultiplier × progressionMultiplier
```

HP、MP、攻撃、防御、素早さ、魔力、魔防へ同じ倍率を掛ける。特殊条件「希少強敵50%」が付いた依頼では通常敵倍率をさらに1.9倍する。

依頼属性に対応する高位スキルを通常5個、EXでは7個まで行動候補へ追加する。特殊条件に応じて属性攻撃+50、HP再生Lv10、食いしばりLv10なども付く。

### レアモンスター

通常はSSR 3%、UR 6%、EX 12%。「希少強敵50%」系の特殊条件では50%。レア個体にも専用の強化倍率を適用する。

### 最下層ボス

候補は依頼属性を優先して選び、依頼生成時に1体へ固定する。

```text
baseBossMultiplier = max(
    1.5,
    1 + ギルドランク添字×0.28
      + 累積ギルドEXP/850
      + storyStep×0.055
      + 深淵実質到達階/120
)

bossMultiplier = baseBossMultiplier × (SSR:1.25 / UR:1.75 / EX:2.5)
```

## 仲間モンスターのスキル成長

### 判定条件

- 勝利後、戦闘へ実際に参加していた仲間モンスターだけが対象。
- 対象モンスターごとに、現在習得しているスキルから次段階が存在するものを抽出。
- 各対象モンスターにつき2%で成長候補が発生。
- 発生時は候補から1技をランダム選択し、確認後に旧技を新技へ置換する。
- 1戦で成立する成長は最大1件。
- 技種別と属性が次段階と一致しない場合は成長させない。
- レベルアップそのものでは新技を覚えない。加入時の技、スキル書、合成、戦後成長が習得経路。
- 仲間モンスターの技枠は最大8。
