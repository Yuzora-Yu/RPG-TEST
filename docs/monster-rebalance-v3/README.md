# モンスター再配置・再調整 v3

入力: `モンスター修正.csv`（通常モンスター196体）

## 実施内容

- CSVの新ランク・登場エリアを `monsters.js` の正本データへ反映
- 5Rank帯ごとの50ID枠で196体を再採番（CSV行順を帯内順序として保持）
- 旧ID(v2)から新ID(v3)へのセーブデータ移行をスキーマ版管理化
- 旧来の高桁IDも新IDへ直接移行
- ランク変更モンスターのHP/MP/攻撃/防御/素早さ/魔力/魔防/Gold/EXPを、既存成長曲線と個体特性から再計算
- 明確に新Rank帯と不釣り合いな27体のスキル構成を変更
- ドロップ抽選をID依存から永続 `dropSeed` 依存へ変更。再採番では種類が乱れず、新ランクに応じた素材等級・消耗品候補へ更新
- ランダムエンカウントはCSVの `habitats` / `abyssFloors` を正本として選出
- 固定討伐クエスト4件は、新配置で対象が出現するモンスターへ依頼文と対象IDを同時修正
- 全モンスター画像を含む完成形 `assets/monsters` を収録

## 適用上の注意

`assets/monsters` は既存フォルダへ追加マージせず、フォルダ全体を本パッケージ版で置き換えてください。新旧IDが同じ数値帯を再利用するため、単純上書きでは旧画像が別モンスターとして残る可能性があります。

## 調整方法

ステータスは、現行通常モンスターのRank別中央値を対数化し、単調回帰で既存の成長曲線を抽出しています。各モンスターが旧Rankで持っていた「耐久型・物理型・魔法型・高速型」などの平均との差を抑制付きで新Rankへ移植しています。ランク不変のモンスターは数値を変更していません。

スキルは機械的な全置換ではなく、属性・種族・役割を維持しつつ、極端な降格で最上位技が残るケース、または大幅昇格で初級技しかないケースを個別に変更しています。
