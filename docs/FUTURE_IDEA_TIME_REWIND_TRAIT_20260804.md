# 将来実装アイデア: 時属性魔族と特性「死に戻り」

記録日: 2026-08-04
状態: 思いつき記録のみ。仕様未承認・未実装。

## 1. 世界観案

サブストーリーに、時間へ干渉する「時属性魔族」を登場させる案。
戦闘不能や敗北の直前へ一度だけ戻る能力を、敵ギミックまたは加入後の特性として扱う。

## 2. 特性案

名称案: **死に戻り**

ユーザー提案の中心仕様:

- 戦闘中一度だけ発動。
- 死亡直前のターンへ戻す。
- 味方全体のHP・MPを `特性レベル × 10%` 回復する。

## 3. 未決事項

- 発動条件を所持者の死亡時にするか、味方全滅時にするか。
- 戻す地点を「ターン開始時」「致死行動の直前」「死亡判定の直前」のどれにするか。
- 敵HP・MP、状態異常、バフ・デバフ、行動順、乱数状態、消費アイテムをどこまで巻き戻すか。
- ボスの形態移行、戦闘イベント、特殊会話を巻き戻すか。
- 複数所持者がいる場合の優先順位と、戦闘中一度の共有範囲。
- 特性レベル上限と回復割合上限。
- 逃走、訓練戦、イベント敗北、強制敗北での扱い。

## 4. 実装上の重要方針

現在の `Battle.win()` 失敗時ロールバックは、保存・報酬・進行を守るための技術的な安全機構であり、ゲーム能力として流用しない。

将来実装する場合は、次の専用機構を設ける。

1. ターン開始時に戦闘専用スナップショットを作る。
2. 戦闘IDとターン番号を付ける。
3. `deathRewindUsed` 等の一戦一度フラグを戦闘データへ保存する。
4. 発動時に許可された戦闘状態だけを復元する。
5. HP・MP回復を復元後に適用する。
6. 報酬・討伐・クエスト・消費確定前だけ発動可能にする。
7. リロードで再発動回数が戻らないよう結果ジャーナルとは別に永続化する。

## 5. 今回の対応

企画メモへの記録のみ。
敵、特性、シナリオ、マスター、セーブ値への追加は行っていない。
