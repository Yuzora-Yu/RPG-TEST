# セーブ互換・補正処理整理台帳 2026-08-03

## 目的

PRISMA ABYSSに残るセーブ互換、旧仕様補正、実行時再整合処理を分類し、短期救済コードを2026-08-15以降に安全に削除できる状態へ整理する。

今回追加した短期補正は、`data.system.oneTimeMigrations` の明示IDで一度だけ実行する。単なる真偽フラグではなく、完了時刻、変更有無、対象件数を保存する。

## 削除候補日

- 最短削除検討日: **2026-08-15**
- コード上の目印: `App.compatibilityMigrationRemovalDate = '2026-08-15'`
- 日付だけで機械的に削除しない。対象版が十分に配布され、旧セーブの移行確認が取れた後に削除する。

### 転生成長再構築の制約

旧セーブには、各レベルで引いた乱数、Lv50/Lv100の成長ボーナス乱数、当時装備していた成長特性、育成アイテム使用履歴が完全には保存されていない。このため、過去のレベルアップを一回ずつ完全再現することはできない。

今回の補正は以下を守る安全側の集計再構築である。

- キャラクターマスター基礎値は下回らない。
- 新規に追跡する `permanentStatBonuses` は縮小対象から除外する。
- 既存の基礎値超過分を、旧式と現行式の累積成長重み比で縮尺する。
- 現在HP/MPは新しい最大値以内へ補正する。
- 仲間モンスターは別の成長型移行があるため対象外とする。

旧版で使った育成アイテムの履歴は分離不能なため、その分も成長分と一緒に縮尺される可能性がある。今後使用する育成アイテムは `permanentStatBonuses` へ記録される。

## B. 長期保持すべきスキーマ移行

以下は短期バグ救済ではなく、古いセーブ形式を現在形式へ変換する基盤である。旧版セーブの読込を継続する間は残す。

### 仲間・成長

- `migrateMonsterAllyGrowthV1`
  - 高Rank時の実値を成長基礎へ保存していた旧仲間モンスターを、成長型マスター・スキーマ3へ移行する。
- `migrateMonsterAllySkillPointsV1`
  - 加入時SP仕様導入前の仲間モンスターへ、加入Lv相当のSPを補填する。
- `backfillLimitBreakLegacy`
  - 旧LB単値を、現在のソース別LB進行へ割り当てる。
- インポート時の通常仲間/仲間モンスターのスキル枠・転生/合成回数正規化。

### 深淵エリア・階層

- `migrateAbyssRegionSave`
  - 旧深淵ワールド座標、帰還地点、概念世界アンカー、地域進行を現行マップへ移す。
- `migrateAbyssFloorSchemaData`
  - 旧1〜200階一体型データを、物語深淵1〜100階とランダム深淵へ分離する。
- `purgeRemovedLegacyAbyssBossReferences`
  - 廃止済み旧深淵ボスIDの戦闘・図鑑・依頼参照を除去する。
- `migrateMonsterIdReferences`
  - モンスターIDスキーマ変更を、図鑑、討伐数、戦闘、依頼等へ反映する。

### イベント・戦闘再開

- `StoryManager.ensureEventJournal` 内の旧 `pendingEventId` / `pendingBattleWinEventId` / `activeEvent` 移行。
- 戦闘結果ジャーナル、フェーズ遷移ジャーナル、固定ボスコンテキストのスキーマ復元。
- レイラ加入イベントの旧途中状態救済。

### 設定・進行値

- 旧BGM/SE単一音量から、フィールド/戦闘/UI別音量への移行。
- コイン消費累計報酬の旧セーブ初期化。
- 欠落した初期データ、配列、設定値のデフォルト補完。

## C. 継続的な再整合処理

以下は「一度だけの移行」ではなく、壊れた途中保存や複数機能の進行差を毎回安全に整える処理である。短期移行と一緒に削除しない。

- `reconcileDerivedProgressFlags`
  - 正本フラグ群から派生フラグを再構築する。
- `reconcileCarmenaGateProgress`
  - 北門二将の討伐記録とゲート進行を相互確認する。
- `restoreCompletedSwitchGates`
  - クリア済みスイッチ扉のマップ状態を復元する。
- `Dungeon.repairLoadedRandomFloorIntegrity`
  - ランダムダンジョン途中保存の到達可能性を修復する。
- ダンジョン背景テーマ対の片側だけが保存された旧状態の補修。
- 固定ボスの戦闘結果ジャーナル、戦後イベント、位置情報の再照合。
- 戦闘フェーズ遷移・ボス第二形態の再開処理。

## D. 2026-08-15以降の削除手順

1. 最低配布版と対象プレイヤーセーブの到達率を確認する。
2. 以下の代表セーブを複製して、移行済みであることを確認する。
   - アゼルガラグ終極討伐済み、関連討伐数欠落。
   - 転生1回、5回、6回以上の複数キャラクター。
   - 加入済みLv100ギルガメッシュとゼノン。
   - ルーナ/ゼノンクエスト完了直後、戦闘後、別マップ移動後。
3. `oneTimeMigrations` の対象IDが記録されていることを確認する。
4. 短期関数の呼出しだけを先に外し、全回帰テストを行う。
5. 次の版で問題がなければ関数本体とV1旧フラグ処理を削除する。
6. 長期スキーマ移行、結果ジャーナル、固定ボス再開処理は残す。

## 必須回帰観点

- 旧セーブ読込直後と再読込後で二重補正されない。
- 保存失敗時に移行フラグだけ立たない。
- 討伐数補正で報酬、実績、クエスト報酬を再付与しない。
- ギルガメッシュの現在HP/MP比率を不自然に落とさない。
- ルーナ/ゼノン以外の固定ボス描画を消さない。
- イベント途中、結果コミット済み、第二形態移行中の再開を壊さない。
