# Phase2I 実装記録 2026-08-04

## 実装範囲

### 属性結晶片を耐性の正本へ変更

- 火・水・風・雷・光・闇の各属性結晶片を一個以上所持している間、現在の仲間全員へ対応属性耐性+20%を動的付与する。
- 加入時点や加護取得時点の個体コピーではなく、能力計算時の所持判定を正本としたため、加護取得後に加入した仲間にも同じ耐性が適用される。
- 主人公、通常仲間、仲間モンスターを同じ環境耐性計算へ通す。
- 結晶片を失った場合は、その属性の+20%も外れる。旧 `abyssSpiritBlessings` はイベント進行の記録として保持するが、恒常耐性の正本には使わない。
- 旧加護フラグだけを持ち結晶片が欠けるセーブには、一度限り移行 `20260804_spiritFragmentResistanceSourceV1` で対応する結晶片を補填する。
- 最終試練等で参照する属性加護数も、結晶片所持状態から算出する。

### 天使の試練

- 通常ボス流用ではなく、ランダム深淵専用の戦闘コンテキストへ分離した。
- 現在階層+15相当の通常敵を3体生成し、基礎戦闘能力をさらに1.35倍する。
- 勝利時は永続能力上昇を3回確定する。
- 勝利確定と報酬を戦闘結果ジャーナルへ接続し、同じ戦闘IDで二重付与しない。
- 敗北、逃走、保存失敗では勝利報酬を付与しない。

### 深淵の亀裂

- 現在階層+10相当の通常敵を3体生成し、基礎戦闘能力を1.25倍する。
- 勝利時の装備報酬を+3で固定する。
- 戦闘結果コミット後、フィールド復帰時の報酬受取を再開可能にした。
- 亀裂履歴と受取待ち状態を保存し、再読込時の報酬消失・二重受取を防ぐ。

### ランダム冒険者

話しかけた時点で結果を一度だけ抽選し、NPC削除と結果保存を先に確定する。画面遷移や再読込による再抽選は行わない。

| 結果 | 確率 | 実装 |
|---|---:|---|
| 装備取得 | 30% | 現在階層+5相当の+3装備を一個取得 |
| 腕試し | 30% | 正式monster ID `302001`「深淵門将ガレオン」を現在階層+10相当へ強化して戦闘 |
| 道具屋 | 20% | 重複なし5商品。各枠5%で特性書候補。通常価格の50%～300% |
| ハンター召喚 | 10% | フロアへ5体配置。移動速度1.5倍。一体ごとに現在階層+20相当の通常敵3体 |
| レア奇襲 | 10% | レアモンスター5体と即時戦闘。プレイヤー先制、オート戦闘を強制解除 |

ユーザー指定の呼称は「レオン将軍」だったが、既存正式マスターID `302001` の名称は「深淵門将ガレオン」であるため、ID・名称を改変せず既存正本を利用した。

### 既存マップ流用階

- 新規ランダム階生成時、10%で既存マップの地形を流用する。
- 対象は始まりの洞窟、風穴、イグニス火山、禁断の森、クレナ石灰洞、海底神殿、雷砦、大塔、光の宮殿、闇の城。
- 既存イベント、固定出口、NPC、宝箱等は持ち込まず、地形だけを利用する。
- プレイヤー開始位置と階段を到達可能領域内へランダム配置する。
- 宝箱を障害物として仮配置したうえで到達可能性を再検査し、階段経路を塞ぐ配置を拒否する。
- 途中保存読込時は既存のランダム階整合修復へ接続する。

### 特殊階層

新規生成された通常階だけを対象に、一階につき最大一種類を抽選する。突入時にシステム会話で説明し、説明済み状態を保存して再読込時の無限再表示を防ぐ。

| 種別 | 確率 | 効果 |
|---|---:|---|
| 強敵の財宝階 | 5% | 敵能力1.35倍、レアドロップ率2倍、+3装備抽選へ20ポイント加算 |
| 希少種の気配 | 4% | レアモンスター遭遇率2倍 |
| 物語の残響 | 3% | 歩行エンカウント率0.45倍。通常敵の代わりに物語ボス外見の強化個体。能力1.15倍、HPは同階通常敵基準の約2倍 |

物語の残響個体は報酬上は通常敵として扱い、物語ボスの固定報酬、確定+3、形態移行、ストーリー進行を持ち込まない。

### 深淵101階以降の災厄の楔

- ランダム深淵の表示階層101階以降に出現する通常ボスを対象に、勝利結果確定時10%でitem ID `98`「災厄の楔」を一個追加する。
- 専用ボス、天使の試練、深淵の亀裂、冒険者の腕試し、ハンター、レア奇襲、訓練所、ギルド依頼は対象外。
- 抽選結果を戦闘結果ジャーナルへ保存し、同一戦闘IDで二重付与しない。
- 10%境界は `random < 0.10` とし、ちょうど0.10は不発。

### 【EX】装備の基礎能力調整

- ギルガメッシュ報酬の【EX】装備は、オプション数・ランダム特性・固定特性を維持し、基礎7能力だけを従来値の55%へ調整した。
- 報酬生成階層は `250 + 完了討伐数×5`、上限400とした。
- 新規装備には調整済みバージョンと生成条件を記録する。
- 既存【EX】装備は一度限り移行 `20260804_specialBossEquipmentBalanceV1` で、HP・MP・攻・防・速・魔・魔防だけを55%へ縮尺する。
- 既存装備のUID、部位、名称、強化値、付与オプション、固定特性、ロック状態、装備者を維持する。旧乱数履歴がないため再生成は行わない。

## 追加監査で修正した既存不具合

- 通常レア遭遇分岐が、生成に成功したレア個体を `isRare` 条件で逆に除外していたため、レアモンスターが実際には出現しにくい問題を修正した。
- ハンター戦の結果ジャーナルへ未定義の `randomHunterOutcome` を保存しようとする経路を修正し、勝利確定と一度限り消滅を接続した。
- 災厄の楔は結果ジャーナルの保存欄だけが先行しており、抽選処理が未接続だったため、正式ヘルパから勝利確定処理へ接続した。
- 専用ボスの設定済みアイテムドロップで、同じ表示ログを二重追加し得る重複処理を除去した。
- ハンター配置候補が厳格条件で5マス未満になる場合でも、到達可能な通常床が5マス以上あれば必ず5体配置できるフォールバックを追加した。
