作成日: 2026-08-03

## 1. このフェーズの範囲

本フェーズでは、レガシオン技法書店の再整理、ふるびたコイン累計消費報酬、Rank120以降の直接マスター調整を実施した。

実装済み:

- レガシオンのクリア後技法書店を109種から10種へ縮小
- 蘇生・ブレス・中級回復／補助中心の品揃えへ変更
- ふるびたコインの累計消費枚数を新規記録
- 10～500枚の累計消費報酬8段階を新設
- 交換所に「累計報酬」メニューを追加
- 旧セーブで復元可能な過去消費枚数を一度だけ補完
- Rank120以降の通常敵・強敵75体を直接マスター強化
- 同75体の経験値を大幅に減額
- 終盤ストーリーボス8体を直接マスター強化し、経験値を調整
- 六属性の精霊試練ボス6体を直接マスター強化し、経験値を調整
- 同日分の更新内容を既存の `news.js` 1レコードへ追記

このフェーズでは、ボスの使用スキル、ギルド依頼迷宮、ランダム迷宮、亀裂報酬、深淵101階以降の生成、ギルガメッシュには変更を加えていない。

## 3. ふるびたコイン累計消費報酬

### 3.1 判定基準

累計報酬は、ふるびたコインの取得累計ではなく、交換所で実際に消費した枚数で判定する。

新規統計:

```text
totalCoinsSpent
```

交換が正常に完了した場合だけ加算する。所持不足、景品装備生成失敗、受取処理中断では加算しない。

### 3.2 メニュー

ふるびたコイン交換所の最上位メニューへ次を追加した。

- ふるびたコインを交換する
- 累計報酬

累計報酬画面上部には累計消費枚数と、次の報酬までの残り枚数を表示する。

各報酬は以下の状態を表示する。

- 未達成
- 受領
- 受取済

受取済み達成値はセーブデータへ記録し、同じ報酬の二重受領を防止する。

### 3.3 報酬マスター

`database.js` の `DB.COIN_SPENDING_REWARDS` に正式マスターとして追加した。

| 累計消費 | 報酬 |
|---:|---|
| 10枚 | 上やくそう×5 |
| 30枚 | 魔法の聖水×5 |
| 50枚 | 世界樹の葉×2 |
| 100枚 | 世界樹の雫×2 |
| 150枚 | 神霊の雫×1 |
| 200枚 | スキルのたね×5 |
| 300枚 | 転生の実×1 |
| 500枚 | 転生の実×1、合成の壺×2 |

### 3.4 旧セーブ補完

旧セーブには正確な交換履歴が存在しないため、初回移行時に次の値を復元可能な過去消費枚数として採用する。

```text
max(0, 累計取得枚数 - 現在所持枚数)
```

一度補完した後は移行済みフラグを保存し、再ロードのたびに再計算しない。

取得履歴自体が記録されていなかった古い経路については完全復元できないため、新規交換以降は `totalCoinsSpent` を正本とする。

## 4. Rank120以降の通常敵

### 4.1 対象

- Rank120～200の通常敵・強敵75体
- 特殊メタルモンスター「プリズムキング」は除外
- ボス、ギルガメッシュ、動的生成個体はこの通常敵処理へ含めない

値は `monsters.js` の各レコードへ直接記録した。ゲーム起動時にマスターを上書きする処理は追加していない。

### 4.2 能力調整

既存レコードの物理型・魔法型・耐久型などの傾向を保ったまま、Rank帯に応じて基礎値を引き上げた。

| Rank帯 | HP | MP | 攻撃・防御・魔力・魔防 | 速さ |
|---|---:|---:|---:|---:|
| 120～139 | 旧値の約1.8倍 | 約1.25倍 | 約1.25倍 | 約1.10倍 |
| 140～159 | 約2.0倍 | 約1.30倍 | 約1.35倍 | 約1.12倍 |
| 160～179 | 約2.2倍 | 約1.40倍 | 約1.45倍 | 約1.15倍 |
| 180～200 | 約2.5倍 | 約1.50倍 | 約1.60倍 | 約1.20倍 |

これは編集時の基準であり、実行時倍率ではない。最終値は全対象レコードに整数として保存されている。

### 4.3 経験値

Rankと想定プレイヤーレベルの対応を概ね次のように置いた。

```text
想定プレイヤーレベル ≒ モンスターRank ÷ 2
```

通常編成を2～3体としたとき、後半でも1戦ごとにレベルアップせず、概ね数戦で1レベルになる水準へ減額した。

代表例:

| モンスター | Rank | 旧EXP | 新EXP |
|---|---:|---:|---:|
| エビルレオン | 121 | 6,250 | 2,300 |
| デビルキング | 146 | 22,275 | 7,500 |
| 屍竜ファフニール | 176 | 60,225 | 14,600 |
| 竜王ティアマト | 196 | 80,000 | 12,800 |
| 深淵宝匣アケロン | 190 | 63,000 | 19,550 |

全対象の旧値・新値は `docs/RANK120_MASTER_ADJUSTMENTS_20260803.csv` に記録した。
