# 仲間キャラクター画像 v2

現行の `assets/characters/char_face_<ID>.gif` は未変更です。このフォルダは確認・採用前の新画像を隔離します。

## ファイル構成

- `fullbody/char_full_<ID>.png`: 頭頂から靴底まで入る全身画像
- `portraits/char_face_<ID>_normal.png`: 全身画像から切り出した通常表情
- `portraits/char_face_<ID>_sad.png`: 悲しむ
- `portraits/char_face_<ID>_angry.png`: 怒る
- `portraits/char_face_<ID>_happy.png`: 喜ぶ
- `portraits/char_face_<ID>_shout.png`: 気合を入れて叫ぶ

## 統一規格

- 全身: 縦長、成人は約7.5頭身、頭頂・両手・両足を欠かさない、人物高は画面の約82%。
- 上半身: 954×954、頭頂から腰付近まで、頭部と肩幅の占有率を全員で揃える。
- 表現: 高品質な2D日本式JRPG、明瞭な線、落ち着いたセル塗り＋控えめな絵画質感。
- 維持項目: 年齢、顔立ち、髪型、配色、衣装構造、紋章、武器、人物の雰囲気。
- 背景: 全身・上半身・全表情ともRGBAの完全透過PNG。四隅のalpha=0、輪郭の色かぶりなしを確認する。
- 装備: 元画像に描かれている武器・道具は人物要素として保持してよい。元画像にない武器、鞘、武器用ストラップなどは新規追加しない。職業は `characters.js` を正本とし、衣装・姿勢・体格でも表現する。
- 人工感対策: 意味のない細密装飾、過剰な金属反射、プラスチック状の肌、左右対称すぎる顔、エアブラシ光、構造不明な縫い目を避ける。線幅にわずかな人間的揺らぎを持たせ、必要な箇所だけ質感を描く。

表情差分は通常画像を編集元にします。第一選択は、頭部中心、首、両肩、胴体、衣装、装備、画像内の接地点を同一座標に固定し、目・眉・口・頬だけを変更する方式です。数ピクセル以上の位置ずれや胴体の再描画差が出たものは採用しません。

固定差分は、生成した表情ソースを完成画像として直接採用せず、通常画像を最終キャンバスにします。左右の眉・目と口を独立した小さなソフトマスクで合成し、顔全体を一括合成しません。鼻、頬の外周、顎輪郭、髪、耳、首、襟、肩、武器、衣装、胴体、最終画像のアルファは通常画像から保持します。少なくとも顎より下が通常画像とピクセル一致することを機械確認し、GIFの全フレームを拡大した一覧でも髪際・耳・顎・首・襟を目視確認します。

ただし、生成元と通常画像の顔の縮尺、目鼻口の高さ、顎形状が一致しない場合は、局所合成を一切行いません。わずかでも貼り付け感や境界の不自然さが残る画像は不採用とし、通常画像をキャラクター設計の参照にした全体再描画へ切り替えます。この方式では、顔・髪・衣装・紋章・装備の設計を維持しつつ、感情が明確に伝わる上半身ポーズとして頭部から胴体まで一続きに描きます。Joseph（ID 101）の喜び・叫びはこの全体再描画方式です。

位置固定が安定しない人物では、中途半端な揺れを残さず、感情に対応した明確なポーズ差として作ります。その場合もキャラクターの基準位置と頭部中心は揃え、会話切替時に意図した演技として読める変化に限定します。

生成時は一度だけ均一なクロマキー背景を使い、専用処理でアルファ化します。クロマキー色は人物の髪・瞳・衣装・装備に存在しない色を選びます。標準は緑 `#00ff00`、緑系人物はマゼンタ `#ff00ff`、両方と衝突する場合はシアン等の第三色を使います。クロマキー画像は最終成果物として残しません。
