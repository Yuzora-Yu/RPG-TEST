# 深淵再編・統合チェックポイント2

作成日: 2026-07-28

このZIPは、深淵大幅再編の現在までの更新ファイルをまとめた確認用パッケージです。
元の `achievements.zip` および前回の途中版ZIPには上書きしていません。

## 安全な適用方法

1. 現在のゲームフォルダとセーブデータを別名でバックアップしてください。
2. このZIPを別フォルダへ展開してください。
3. `CHANGED_FILES.txt` を確認し、ゲーム本体の同じ相対パスへ上書きしてください。
4. `assets` は含まれていません。新規モンスターは既存の有効な `imageId` を参照して暫定流用しています。
5. 既存セーブを使う場合は、複製したテスト用セーブで先に確認してください。

誤上書きを避けるため、自動適用スクリプトは同梱していません。

- 深淵を固定MAPではなく、切替可能な第二ワールドとして登録

- カルメナ、ビスタ、レガシオンと付属施設の正本MAP定義
- 指定ダンジョン群の固定階・可変階・往復階段・再入場再生成
- ダンジョン別属性耐性低下とステータス表示反映
- カルメナ汚染と、門番二将撃破後の解除
- 新規通常モンスター55体、ボス22体、重要アイテム、技法書、専用スキル
- 対象ダンジョン11MAPへ各5体の新規通常モンスターを生息地正本から登録
- 新規深淵全域とクリア後ランダム深淵での低確率仲間化
- 結界解除、都市通過、終盤ルート、精霊戦、エピローグ、クリア後亀裂の進行
- ヴェグナシスの5対象戦、柱撃破時の残存強化・全回復・戦闘内会話

- 旧深淵セーブから新進行への移行処理
- 目的表示、実績、旧深淵メニュー解放条件の再編

## 現時点の設計判断

夢幻回廊リドパルムは、仕様文内の「6層目中央」「1～3層と4～6層」「3層目は迷路確定」を優先し、全6層、2～5層を可変階、3層目を迷路確定として実装しています。
「間の2層」を文字通り可変2層だけにする意図であれば、次の更新で階層構成を変更する必要があります。
