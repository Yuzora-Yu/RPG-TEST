# PRISMA ABYSS 終盤戦闘・固定ダンジョン修正報告

更新日: 2026-08-01

## 対応概要

途中版 `PRISMA_ABYSS_endgame_dungeon_fix_PARTIAL_20260801.zip` を基準に、未完了だったレガシオン全接続とプリズム精霊戦を含め、依頼された項目を統合しました。

## 1. アゼルガラグ第一形態から第二形態への移行

### 原因

第一形態のHPが0になった後に第二形態へ差し替えていましたが、変身会話の終了後も第一形態側の古いターン処理が継続していました。自動戦闘時には新しい入力処理と古いターン処理が重なり、戦闘状態が進行不能になる可能性がありました。

### 修正

- 第一形態 `302100` の撃破を通常の戦闘終了判定へ渡す前に捕捉。
- 同じ敵スロットを第二形態 `302101` へ置換。
- 第二形態のHP・MPを全回復。
- パーティーを回復し、既存仕様の能力強化を適用。
- 変身会話を実行。
- 会話終了後は古いコマンドキューと行動者を破棄し、次の入力フェーズを新しいタスクとして開始。
- 古いターン処理はその場で終了させ、第二形態のターンへ混入させない。

第一形態撃破時には戦闘終了処理を走らせず、第二形態撃破時だけ勝利処理へ進みます。

## 2. ヴェグナシス戦の柱撃破イベント

### 原因

柱の撃破イベント検出より先に、共通撃破処理が `isDead` を設定していました。旧検出条件では「直前まで生存していた柱」を正しく取得できず、会話・回復・強化が発生しませんでした。

### 修正

- HP0かつ未処理の柱を `abyssFallHandled` で検出。
- 柱ごとに一度だけ撃破イベントを発生。
- 複数柱を同時に倒した場合も、柱番号順に各イベントを処理。
- 残存する柱へ以下を適用。
  - 最大HP 1.18倍
  - 最大MP 1.12倍
  - 新しい最大HPの20%回復
  - MP全回復
  - 攻撃・防御・素早さ・魔力・魔防を1.18倍
- 戦闘途中セーブにも `abyssFallHandled` を保存し、再開後の二重発生を防止。

## 3. 魔力循環

次の3体に特性ID `53`、レベル5の「魔力循環」を追加しました。

- イルミナシア `302070`
- アゼルガラグ第一形態 `302100`
- アゼルガラグ第二形態 `302101`

MP全消費技の後も、ターン経過でMPを再確保できます。

## 4. レガシオン内部MAPの接続

### 修正方針

固定MAP同士の移動で地上ワールドへ戻ったり、帰還点が内部移動のたびに上書きされたりしないよう、個別の座標補修ではなく固定MAP共通遷移を修正しました。

### 対応

- レガシオン関連7MAPへ `worldKey: "ABYSS_WORLD"` を設定。
- 固定MAPから別の固定MAPへ移動する場合は、ワールド帰還点を上書きしない。
- 接続先の `entryKey`、`targetX`、`targetY` を正本として使用。
- 旧セーブで内部MAPの `worldKey` が地上側へ落ちている場合も、固定MAP定義から補正。
- 階段タイル `S` が固定MAPを指す場合、ワールド復帰処理ではなく固定MAP遷移を使用。

### 接続一覧

- レガシオン本館 ↔ 上層回廊
- レガシオン本館 ↔ 地下牢
- レガシオン本館 ↔ 地下神殿
- 上層回廊 ↔ 謁見の間
- 上層回廊 ↔ 西塔
- 上層回廊 ↔ 東塔
- レガシオン南門・北門 ↔ 深淵ワールド

各入口・帰還先は通行可能タイルへ接続されています。

## 5. プリズムからの精霊戦

### 原因

プリズム本体は通行不能の装飾画像でしたが、対応する `mapAction` が「隣接操作可能」として登録されていませんでした。足元へ乗れない一方、隣接アクションにも拾われない状態でした。

### 修正

6属性すべてのプリズムへ以下を設定しました。

```js
interactFromAdjacent: true,
blocksMovement: true
```

対象:

- 火: イグナ火山
- 風: 風の神殿
- 水: 海底神殿
- 雷: 雷の要塞
- 光: 光の宮殿
- 闇: 魔王城

レガシオンの神官から話を聞き、`abyssSpiritPrismKnown` が立った後、各プリズムの隣接マスから「調べる」で精霊戦を開始できます。

- 精霊戦に敗北してもプリズムは消えません。
- 固定ボス討伐済み座標には登録しません。
- 再訪して再戦できます。
- 勝利済み属性だけ加護取得済みとして扱います。

## 6. 深淵の固定ダンジョン内にあるランダム生成部分の宝箱

対象を `isFixed && generatedFromAbyssLogic === true` のMAPだけに限定して、取得済み宝箱を床へ戻すよう変更しました。

対応箇所:

- 表示オーバーレイ
- タイル描画
- 現在タイル取得
- 移動前判定
- ミニマップ・記号表示
- 通常報酬、鍵、空箱、トラップの各取得経路

トラップ戦で全滅した場合は開封状態と床化を巻き戻し、宝箱を復元します。通常の固定宝箱や物語上残す必要がある宝箱には適用しません。

## 7. ジャゴレアのランダム生成

### 原因

旧生成処理に横幅を拡張する `wideProcedural` と、右側へ大きな長方形区画を追加する処理がありました。生成本体との接続が保証されず、到達不能な巨大空間や宝箱配置が生じていました。

### 修正

- `wideProcedural` と右側巨大区画の追加を削除。
- 生成サイズを標準化。
- ランダム生成開始点を含む通行可能な連結領域を正本にする。
- それ以外の切り離された領域を壁へ戻す。
- 入口・出口・宝箱を連結領域確定後に配置。
- 固定ランダムMAP生成バージョンを3へ更新し、旧キャッシュのジャゴレア2～4階を再生成。

## 8. 戦歴メニューからギルド依頼迷宮へ挑戦

受注済み・未完了の `guildDungeon` クエストについて、戦歴メニューのギルドタブへ「依頼迷宮へ挑戦」を追加しました。

- 受注前・完了済みには表示しない。
- 既に別の依頼迷宮へ挑戦中の場合は重複開始しない。
- 戦歴画面を閉じて、既存の `Guild.startChallengeQuest()` から開始。
- ギルド受付から開始する既存経路も維持。

## セーブ互換

- レガシオン内部MAPの誤った `worldKey` は固定MAP定義から補正。
- 固定ランダムMAPは生成バージョン更新により、旧ジャゴレア生成キャッシュだけ再生成。
- ヴェグナシス柱の処理済み状態は、今後の戦闘途中セーブに保存。
- 既存の物語フラグ、討伐フラグ、所持品、キャラクター状態は変更しません。
