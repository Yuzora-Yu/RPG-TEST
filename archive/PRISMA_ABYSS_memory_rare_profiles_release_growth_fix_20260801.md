# PRISMA ABYSS 修正内容

## 対象

- 回復の泉とイベント／通行不能オブジェクトの重複時操作
- 追憶の魔境のレアモンスター
- 追憶の魔境の全モチーフ共通6種
- 仲間モンスターの「逃がす」
- 仲間モンスターのレベルアップ成長係数

## 1. 回復の泉

前回修正で確認済みの重複座標は、イベント座標を維持し、回復の泉を隣接する通常床へ移動済みです。

今回さらに、固定マップの回復の泉がイベント、階段、装飾などと同じ通行不能マスに残った場合でも、隣接マスから「泉で回復」を実行できる共通処理を追加しました。

- 現在地に泉がある場合：従来どおり現在地から利用
- 隣接する通行不能マスに泉がある場合：隣接位置を対象に利用
- 回復対象座標を `Dungeon.useHealSpring(targetX, targetY)` へ明示
- 固定泉は常設、ランダム泉は一度使用すると消滅する既存仕様を維持

## 2. 追憶の魔境のレアモンスター

メタルジェリー、ロンリーメタルは通常のRank比例生成を通さず、専用生成に変更しました。

維持する個性：

- 元の低HP
- 防御・魔防9999以上
- 全属性攻撃無効
- 元の状態異常耐性
- 元の行動テーブル（逃走コマンドを含む）
- 元の回避・命中・会心
- 元のドロップ設定
- 元経験値・ゴールドを基準に、追憶の魔境のRankに応じて報酬だけ比例強化

物理攻撃は通常の最低ダメージ規則により0または1相当となり、属性攻撃は0ダメージになります。会心や防御無視など、既存戦闘システム上の対抗手段は維持します。

## 3. 全モチーフ共通モンスターの役割固定

全モチーフ共通候補を6体に変更しました。

| ID | モンスター | 役割 | 属性・行動 |
|---:|---|---|---|
| 503 | リトルメイジ | 魔法特化 | 火属性主体 |
| 507 | アクアリリィ | 魔法特化 | 水属性主体 |
| 604 | ライトリリィ | 魔法特化 | 光属性主体 |
| 752 | スカウトデビル | 物理特化 | 闇属性・物理主体 |
| 654 | ヒールフェアリー | 魔法特化 | 風属性主体・全体回復あり |
| 655 | キラーマシン試作 | 物理特化 | 雷属性・物理主体 |

この6体については、選定されたフロア背景の属性で上書きせず、個体固有プロファイルを優先します。スキルは対象Rank帯から、指定属性と物理／魔法種別を厳格に絞って再選定します。

## 4. 仲間モンスターを逃がす

仲間一覧の詳細画面「基本」タブへ、仲間モンスターだけに表示される「この仲間モンスターを逃がす」ボタンを追加しました。

- 通常の仲間キャラクターには表示しない
- 確認ダイアログあり
- パーティ編成中ならパーティからも外す
- 装備品は装備袋へ返却
- 戦闘中は実行不可
- 実行後は取り消し不可

## 5. 仲間モンスターの成長係数

ユーザー記載の「清澄寺」は、文脈上「成長時に」と解釈して反映しています。

### 原因

仲間モンスターの `growthBase` に加入時の実ステータスをそのまま保存していました。Rank91以上の実値を、通常仲間では20～50前後の成長係数として使う値へ入れていたため、レベルアップ成長が過大でした。

### 新仕様

- 加入時の初期ステータスは変更しない
- 通常仲間29名の `growthBase` 中央値を成長総量の基準にする
- 同レベルの通常仲間の概算ステータス中央値と比較して、モンスター固有の能力比率を抽出
- 上位2項目を得意、下位2項目を苦手として保存
- 得意項目は成長倍率を高く、苦手項目は低くする
- 全能力の成長総量は通常仲間の中央値相当に正規化
- 既存のランダム成長、Lv50／Lv100成長、特性による成長補正は共通仕様のまま維持

保存項目：

```js
monsterAllyMeta.growthProfileVersion
monsterAllyMeta.growthStrengths
monsterAllyMeta.growthWeaknesses
monsterAllyMeta.growthMultipliers
growthBase
```

### 既存セーブ互換

`monsterAllyGrowthSchemaVersion: 1` を追加しました。

初回ロード時だけ、既存の仲間モンスターについて：

- 現在レベル
- 現在の素ステータス配分

から得意・苦手を再判定し、`growthBase` だけを正規化します。

現在のレベル、現在ステータス、SP、習得スキル、特性、装備、LBは変更しません。既に過去のレベルアップで増えた数値は巻き戻さず、以後の成長だけを修正します。
