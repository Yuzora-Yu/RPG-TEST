# PRISMA ABYSS Phase2T +3装備取得カード開示演出

日付: 2026-08-05
正本: ユーザー提供 `RPG全差替え.zip` および GitHub `main`

## 監査結果

- 現行カードは戦闘結果ログと同期して表示し、カード入力を戦闘結果送りへ伝播させない構造になっている。
- 戦闘イベント終了後の `battle_event` 復旧処理も現行ソースに含まれている。
- 今回、イベント復旧メソッドと戦闘フックの構造は変更していない。
- 既存の専用テストは、削除済みの `sellActive()` を呼んでいたため現行仕様に合っていなかった。
- 属性補正、状態異常補正、固有習得スキルは、現行カードの基礎効果生成処理では表示対象から欠落していた。

## 実装

### 表示補完

- `elmAtk` / `elmRes` の属性攻撃・属性耐性を表示。
- `resists_*` の状態異常耐性を日本語名で表示。
- `attack_*` の状態異常付与率を表示。
- `grantSkills` をスキル名へ解決し、黄色の習得表記で表示。
- 追加オプションの `unit:'val'` が文字として露出しないよう修正。

### 開示順

1. 装備名、Rank、基礎効果、基礎特性は初期表示。
2. 追加オプションを配列順に1件ずつ表示。
3. 各オプションはレアリティ色の横線を先に走らせ、その後に文字をフェードイン・拡大表示して規定サイズへ収束。
4. 追加特性を1件ずつ表示。特性名を先に出し、Lvを後から強く表示。
5. シナジーがある場合だけ最後に表示し、カード周囲へ青緑・紫・緑系のオーロラ発光を追加。

### 操作

- 演出中の最初のタップ／Enter／Space／Escapeは全表示へのスキップ。
- 合成クリックを吸収する待機時間を維持。
- 次の入力でカードを閉じる。
- 戦闘結果カードでは表示中の `Battle.resultInputLocked` を維持し、閉じた後に元へ戻す。

## 非変更

- 保管・売却ボタンは復活させていない。
- 武器・防具屋は表示対象外のまま。
- 戦闘イベント復旧処理、戦闘ログ接続、報酬確定順序は変更していない。
- カードの現行レイアウトを正本としており、旧納品版のレイアウトへ戻していない。
